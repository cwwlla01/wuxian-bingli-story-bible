## 统一规则

- **已确认**和**【工作提案】**严格区分；未获得作者确认的动机、场景对白和细节不能自动成为正史。
- 日照以Day3 06:00日出、日落即夜为基础；Day14完全永夜、Day18白昼恢复。
- 刑纹存在期间**持续疼痛且持续增幅战力**；「定罪」「罪己」「处刑」为现行核心技能链。
- 人物主控时的记忆不自动共享；医院病历登记、医护职责及鬼院长生死按现行阶段大纲与世界机制执行。
