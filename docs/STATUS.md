# 设定状态与冲突消解

## 【已确定】首要正史

- 登岛首批十五人；第1天何雨死亡；第3天九人讨伐指定三阶裂颚者，吴大勇与孙浩死亡；赵骁引怪封仓，魏叔、刘斌、蒋文死亡；六人登船、三人林渊、陈七、苏小满滞留。
- 周启来自上上批，不计入十五人；四人后续结队。死眠仍是活体，触碰必醒；不是免死复活。
- 林渊为心理医生，儿童时有人格分化倾向，寺庙静养三年；他曾治疗现实中的小禾，治疗未完成后小禾失踪。相关魂印机制未揭示。
- 林渊 C级「共情」，阿禾女性独立人格，同享男性身体；S级「处刑者」有固定五种能力；岛上阿月为阿禾潜意识模拟出来的第三人格，不是死去恋人的复活，有自己的主观意识；阿月不可主动使用S级技能。
- 高僧曾言：“念头起时，你看见它；念头落时，你不必追它。” 这句已锁定为寺庙记忆。仓库内钟声所回响的另一关键台词仍待定。
- 仓库林渊精神崩溃时身上出现多道七彩光柱，脑中钟响，高僧点拨回荡，阿禾接管身体；七彩光柱具体机制尚未解答。
- 苏小满外貌有些像现实阿月，温柔善良而胆小。第0天第一次靠岸，苏小满险些跌入海中，林渊救了她，并发现海无正常浮力。
- 苏小满的容貌联想，是仓库里阿禾而非其他人格接管的重要情绪触发因素之一；阿禾随后带陈七、苏小满赶到码头，看海忆起与现实阿月的约定，情绪震荡使林渊重新取得控制权。
- 海完全不具正常浮力；游轮系统航次与怪物复原/领地、整岛复位规则见 `docs/world/`。
