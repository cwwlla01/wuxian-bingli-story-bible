# 苏小满｜独立角色档案（待深化）
**已确定**：首批十五名挑战者之一，B级天赋「灵丝」，可短暂维持丝线用于预警、拦阻、固定、配合；不可突然拥有无限制攻击能力。她温柔、善良，胆小。她和现实中的阿月有几分相似，但不是同一人，也不是阿月的替身。

## D0 码头险情
首批挑战者登岛时，苏小满险些掉进海里，林渊将她救下。这时发现海水不提供正常浮力，坠海者无法正常游泳逃生。**待设定**：以什么可观察的物理证据让众人发现无浮力；险些落水本身不能独立证明。

## D3 仓库事件
赵骁另引一只普通三阶怪物至仓库，魏叔、刘斌、蒋文死亡。小满外貌与阿月的相似性唤起阿禾的保护记忆，是林渊崩溃后阿禾而非其他人格接管的情绪触发之一。阿禾击杀这只普通三阶（不是指定铁颚），带着陈七、小满逃至码头；阿禾见海忆起与阿月看海约定，强烈情绪震荡后林渊恢复控制。

## 后续成长
周启训练林渊、陈七、小满；小满的成长方向不是完全无惧，而是学会带着恐惧行动并保护他人。她拥有独立的人格、选择与成长，不应被写成阿月的替身。
