01｜这条爱情线真正要“虐”的是什么
不是靠更残酷的死亡细节来制造眼泪，而是让观众先爱上两个人“如果没有被拆散，本可以拥有的普通生活”，再亲眼看见她们如何在流言、家庭强制与错位的保护中失去选择。

02｜人物要各自有想要的生活
小禾：想被爱，却深信自己只能成为麻烦
【已明确】她是孤儿女孩，自小受欺负，剪短发，以男孩形象与拳头自保；后来与阿月相爱，悲剧后长期自责，并曾接受林渊未完成的心理治疗。
【工作优化】她的真实弱点不是“爱得不够”，而是习惯用替别人扛下所有问题的方式来证明价值。每当有人靠近，她就本能地寻找“我会害了对方”的证据。她最想得到的是允许自己脆弱，却总在关键时刻选择嘴硬和离开。
阿月：不是温柔牺牲品，她也渴望亲自选择未来
【已明确】她在小禾昏迷后救了她，让小禾相信不用伪装；两人因感情遭村里指责。阿月后来被家庭禁闭、安排婚事，最终离世。
【工作优化】阿月有脾气、有底线，也会生气。她的生活愿望不止“和小禾在一起”，还包括自由出门、靠自己的手艺或工作生活、为自己的将来作决定。她会主动拒绝婚约、争取外援；这些努力受阻，才形成悲剧压力。她不能只是一个用死亡推动小禾变强的角色。
03｜加强版完整故事：八次“先暖后疼”的推进
第一折｜被救的那天，她以为又有人来可怜她
小禾在与人冲突后昏倒。阿月把她带到安全处，守到她醒。小禾第一句便是让她别多管闲事；阿月没有拿“我救过你”索要亲近，只把水放到她够得到的地方，说：“你要我走，我就走。你要喝水，先喝了。”小禾伸手拿起水，却没有说谢。
【虐点种子】第一次有人给她保留选择，而不是逼她服从。未来阿禾会记得的，不是阿月说过多少大道理，而是她当时没有把自己的手强行塞进她手心。
第二折｜树下的小小愿望
她们渐渐熟悉，常在小禾门前的树下歇脚。小禾说话冲，阿月会反驳；小禾习惯用打架解决事情，阿月不肯每次替她收拾残局。两人学会吵架、和好，把生活里再小的事讲给彼此。某次阿月提起海——她们都没见过，但想一起去。小禾嘴上嫌远，实际开始攒路费。这个看似普通的未来，成为两人最珍贵、最终没能共同实现的约定。
【虐点种子】这时必须真有快乐：她们争论海是什么颜色、谁会晕船、走散怎么办。以后看到海的那个人，不该在同一瞬间失去当年的笑声。
第三折｜镜子不是用来证明她是谁
小禾不习惯认真看自己的脸。某次阿月把小镜子递给她，小禾开玩笑说：“你是不是也觉得我这样不像个姑娘？”阿月回：“我只想让你看看，你现在想怎么做，都没人有资格替你说了算。”她没有替小禾决定发型或妆容。小禾第一次主动试了点淡妆，又很快擦掉，两人都笑了。
【联系岛上】后来的夜妆可以承接“曾有一个安全的时刻，让她愿意自己选择如何出现”。这只是情感来源的【工作优化】，并不解释人格切换机制。
第四折｜她第一次公开站在小禾身旁
流言从背后的窃语变成当面羞辱。一次在众人面前，阿月没有假装不认识小禾，而是走过去与她并肩站着。小禾却看见阿月回家后受到的压力。她开始把每一句羞辱都记在自己身上，认为只要自己离开，阿月就能恢复平静。
【虐点种子】阿月选择并肩，小禾却把“保护她”误理解为“替她撤退”。这是两人日后最难解开的错位。
第五折｜最后一次争执，谁都没有说出真正想说的话
小禾提出断开关系，假装冷淡。阿月没有马上哭着挽留，只问：“这是你想要的，还是你替我想好的？”小禾不敢承认害怕，也不敢面对阿月已经承担的压力，只说：“离了我，你会过得轻松些。”阿月生气，因为她最早教小禾不要被别人定义，如今小禾也在替她定义人生。两人分开时，都以为还会有时间解释。
【虐点落刀】小禾最伤阿月的一次，不是骂她，而是没有问过她就替她决定。注意不将这次争执写成阿月死亡的单一原因；真正的困境仍来自外界排斥与家庭控制。
第六折｜门是锁着的，婚期却越来越近
阿月被限制外出，家里定下婚约。她并非完全沉默：她表达不愿意，也尝试找可信的人求助，却被家人阻断或轻视。小禾在外面只得到零碎消息，以为不再出现至少不会让阿月受到更重的苛责。她不知道阿月没有真正选择的机会；阿月也不知道小禾是否还愿意听她说话。
【虐点推进】两人都在为彼此做看似正确的事，却失去沟通条件。观众应知道阿月曾反抗，因此不是把她写成“没有小禾就无法活”的角色。
第七折｜红喜字还在，白布已经挂起
到了婚礼那天，小禾终究赶去。她原本只想隔着人群看一眼，若阿月仍愿意，她就当面听一次她的选择。然而门前的红字尚未撤去，院里已经传出噩耗，有人忙着换白布、收拾喜宴。阿月已经去世。小禾站在门槛外，手里握着一直没舍得花的路费；这笔钱本来是要带她们去海边的。
【虐点落刀】不展示离世的具体过程，也不以自伤作为爱情证明。最痛的是迟来的行动无法再改变结果。门前“红变白”维持作者原意，但采用同日撤换布置的呈现，避免不合理地把完整丧礼压进婚礼当天。
第八折｜树长出新芽，她还是没能回答自己
悲剧后，小禾长期恍惚、自责，曾伤害自己，并在林渊那里接受过未完成的治疗。林渊没有随意告诉她“都过去了”，而试图陪她把自己承担的责任和别人强加的伤害分开。几天前雷电劈坏小禾门前的树，一半焦黑。那天她发现剩下的一半居然生出嫩芽。她走到阿月墓前，像以前靠树一样倚着碑坐下，先说树的近况，随后再也无法维持平静。
【已明确的原始表达】“树死了一半，还能活着。我的心死了一半，你让我如何能活？” 这句话保留；墓前称呼与“次日失踪”的主语仍需核对，详见文末。
04｜看海之约：三次出现，一次迟到
第一次｜树下，说好一起去看海
【已确定】两人有“一起去看海”的约定。【工作优化】约定发生在两人相恋且仍能平静相处的树下：阿月说自己没见过海，想有一天去看看；小禾明明也没见过，却先问路有多远。让她们为路费、天气和走丢这样的小事争论，显得这不是一句誓言，而是可以着手安排的未来。
阿月：“等我们走出这个村子，一起去看海吧。”
小禾：“海那么大，走丢了怎么办？”
阿月：“那你牵着我。”
小禾：“说好了，我带你去。”
以上四句均为【工作台词】，并非作者锁定原话；真正已确定的是“二人约定去看海”。若希望更克制，可以只保留“说好了，我带你去”。
第二次｜墓前，钱攒够了却永远缺了一个人
【工作优化】小禾在婚日或墓前意识到，原本最容易办到的小愿望已经无法共同兑现。可以保留“攒路费”作为日常细节，但不要设定为让观众靠道具找线索的神秘物品。半死的树是“她怎样活”，尚未见过的海是“她曾想怎样活”。
第三次｜遗弃之岛码头，第一次真正看见海
【已确定】仓库危机后，阿禾先救出陈七和苏小满，再带两人奔往码头。望见真实的大海，她突然忆起与阿月的约定，随之涌出部分旧日片段；情绪冲击使身体控制权切回林渊。【工作优化】他们赶到时六名登船者已经离去，海面剩下船影与浪声。真正刺痛阿禾的不是“船走了”，而是“她终于到了海边，阿月却永远无法并肩”。
阿禾（低声，工作台词）：“阿月……海原来是这样的。”
【转折必须清楚】陈七和苏小满看见的是同一具男性身体的呼吸、姿态与眼神改变；不是性别肉体变形。阿禾的记忆闪回属于她的视角，不自动赋予恢复控制的林渊对全部前史的了解。
四人团队尚未形成：此时三名滞留者仍是林渊、陈七、苏小满，周启是此前航次的老挑战者，后续才加入。海水仍无正常浮力，码头不是能跳海逃脱的出口。

07｜与第一季主线的接法：不把悲剧浪费在回忆里
仓库：阿禾以处刑者之力出现，却没有从愧疚中走出
【已确定】仓库内林渊精神崩溃，多道七彩光柱出现，脑中钟声与高僧关键句响起，阿禾接管同一男性身体并击杀一只普通三阶怪物。阿禾随后带着陈七、苏小满逃向码头；看到真实的大海，她回忆起与阿月的看海约定，记忆片段涌现、心神剧烈震动，身体控制权恢复为林渊。阿月绝不会因为这次刺激自动出现。
码头：先救两人，再被那句“说好了”拉回过去
因果顺序必须连续：阿禾在仓库击杀普通三阶 → 保护陈七、苏小满沿真实路径奔向港口 → 船已带走六人，三人错过离岛机会 → 阿禾目睹大海、想起旧约和少量真实旧事 → 强烈情绪冲击使林渊恢复身体控制。林渊的C级「共情」不是此处的主动切换技能，钟声及七彩光柱也无需在码头重播。
虐点不是“看见海就变身”的机关，而是她第一次碰到一个太具体、无法代偿的遗憾。过去那句“我带你去”在大海面前兑现了地点，却永远兑现不了“两个人”。
夜妆：她第一次有机会用自己决定的面貌面对记忆
【已确定】岛上的阿月是阿禾潜意识依据记忆、思念和亏欠模拟形成的人格，并非现实阿月的灵魂、复活或本人登岛。阿禾夜间真实完成化妆后阿月才会出现；阿月不能主动使用处刑者技能，天亮切回阿禾。二者仍是同一身体、不能面对面同时交谈，也不会自动共享全部记忆。作为已形成的独立人格，模拟来源不否定阿月自己的主观感受和当下选择。
【工作优化】最初阿禾化妆未必是为了呼唤阿月，而是重演那次被阿月允许自由选择样子的夜晚。等阿月出现，这件事才转化成她们错时靠近彼此的方式。这个情感解释不等于确认了切换机制的因果。
身份锁定：岛上的阿月是潜意识模拟，不是逝者复活
【已确定】现实里的阿月已离世；岛上的阿月由阿禾潜意识模拟而成，是同一身体里的第三人格，绝不是真实阿月的魂魄、复生者或从别处来到岛上的外部人物。她可以主观相信自己就是阿月，也可以逐步形成自己的愿望与判断。模拟形成的内容以阿禾所知、所记与潜意识推演为基础，不能凭空验证现实阿月从未透露的秘密。
