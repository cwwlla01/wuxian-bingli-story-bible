# 周启｜独立角色档案 v0.7 · 地下储物间初遇

> **最新版作者纠正已生效**：周启一直在B1地下储物间，没有被谁从地下室搬到三楼。原「三楼病房发现周启」与「谁搬了周启」已经作废。文中的【工作方案】仅指作者未指定的对白和动作细节。

## 硬身份【已确定】

- 来自上上批挑战者，退役特种兵教官，A级「不死战躯」，不是首批十五人之一。
- 天赋能够主动进入生命特征极弱的死眠，仍是活人、不是死亡；**不能自己醒**，须另一个活人直接身体接触触发苏醒。任何怪物触碰、岛屿空间校正都不算活人直接触碰。
- 周启战力远高于初期只能勉强对抗I阶的林渊、陈七、小满，但并不无敌，不能单挑V阶。

## 为什么会在B1【本轮作者确定的动机】

在**周启本人当批的正常任务期间**，疗养院**没有怪物**。他一直好奇自己的A级「不死战躯」究竟能发挥什么效果，独自在**地下室储物间**做了一次尝试，竟戏剧性地陷入近乎假死的死眠，直到如今仍未自行醒来。

他**不是为了躲避查房**而选择此处；当年他**并不知道病历、值班者、医生或院长的具体规则**。独自试验、储物间无人打扰是合理场面解释，试验具体方式、当时队友是否知情仍待补。**“那一批正常任务时疗养院无怪”不能扩大成每批72小时全院恒定无怪。**

## 首次苏醒【作者新版本】

三位滞留者首夜在仓库抵门，因村镇物资已尽、返路被怪物封住，逃入疗养院并先在院墙躲夜。进入主楼时，**三人曾看到过入口的疗养院规则牌**；规则具体字句仍待定，不能让周启提前告诉他们。

三人在短暂光照内搜索1—3F取得水与物资。后来听到**疑似夜间查房**的规律脚步或开门声，为了逃避危险沿真实楼梯躲到**B1地下储物间**。

储物间角落里躺着身穿不同批次服装的周启；三人先疑是怪物，继而以为是尸体。**陈七**为了确认身份靠近，实际直接碰到周启裸露的身体。周启从死眠猛然苏醒，凭退役教官战斗本能和A级身体反应，**瞬间将陈七制伏，控制其身体与手臂**，而非只抓住手腕。周启意识到三人不是敌人后才解除控制，彼此交流并结队。

他询问自己睡了多久，得知新一批人到来；他可以讲述上一批情况，却**不知道新发生的疗养院病历机制**，也不知道外面的声音究竟是否真为查房。

周启：院规？我当时来这里的时候，根本没有怪物。

## 后续与能力限制

- **第一次唤醒者陈七（本轮维持）**：好奇触碰，周启本能瞬间制服陈七。
- **后来再次唤醒者陈七（既定）**：周启遭重大危险后主动死眠，被同伴保护，再由陈七**主动冒险接触**唤醒，构成对照。
- 疗养院**第三个夜晚**机制怪正面出现；正式训练林渊、陈七、小满发生在这次危机之后。周启不能一醒就全知医院真实规程。
- **待核**：死眠跨多个航次的生理消耗、何以无人提前接触、岛屿重置是否与其所躺位置产生重叠校正、当年试验的具体条件；既有世界规则只允许真实活体保留、发生重叠时最近有效空间校正，**校正本身不能唤醒**。
