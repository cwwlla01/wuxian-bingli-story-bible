# 《无限病历》第一季｜第十一轮101集节奏与集界审查

> **审查快照：2026-11-08 · 编辑分支 `editorial/2026-11-08-pacing-pass-1` · PR #2 草稿，未合并main。** 本报告为**模型对实际剧本的结构筛查与重点剧集自审**，**不是人工试读、实地排练、成片观看或时长认证**。数字和预算只描述文本与编剧估算，不能推出观众留存率。

## 一、审查口径与结论

- **目标**：保留第一季EP001—EP101及作者确定的主题结局；横屏AI动画制作目标约60—90秒/集。不得为凑时长增加空镜或把计划文字冒充上屏事件。
- **结构盘点**：五个现行阶段文件共有**101个不同集号**，顺序连续，每集有明确的SC分场；五阶段分别22、8、8、37、26集。
- **版本对比**：与main的剧本正文存在差异的共有**79集**。第十一轮对**15集**实写完整替代分场，均已提交原草稿PR；其余集的“本轮保持原文”或“此前已修改”都不等于本轮新评审通过。
- **纸面预算**：本轮15集新预算的数学加总已复核，**其中11集上限大于90秒**（尚未经过演员演读）。这是风险提示，不是断言它们会超时；本轮没有任何真实计时结果。
- **真实事件与作者约束**：核心死者、六人登船与三人滞留、Day3首船两小时相对钟、Day14无日出与Day18复光、双三阶甲乙均由阿禾独立实体杀死、医院双登记永久有效、两次“罪己”与院长战“处刑”不能无价释放。

## 二、本轮已修复的三条集界

1. **EP011→012：仓库清理负荷重分。** 原精确怪物数是制作候选，不是作者锁定；新候选是**8只I＋2只II＝10只**，仍属于“约十来只，其中两只II”。EP011在仓外真正杀①—④，旧板裂、绳磨毛；EP012转入原分拣铁门杀⑤—⑧与II甲乙。EP012负荷有所下降，但**88—120秒**仍有超时风险，未关闭问题。
2. **EP036→038：离镇决策的不同体验。** EP036放弃未搜商铺、选择旧水道，林渊按陈七指路实画草图；EP037小满亲试残桥石沿，林渊在真痛中求扶；EP038空瓶在实际可够到的墙脚发声引怪，三人守到Day5并发现凹位已暴露。**此三集不靠重复地图与守夜承诺来补时长**。
3. **EP083→090：医院两路与BOSS战形成递增代价。** EP084门厅挡不了IV护士于是分队；EP085第三声意外误响，二楼**隔廊手势确认而非先重聚又拆组**；EP086真的挪开后勤门旧病床，为EP091背负昏迷者留出真实宽口，主梯也可原路撤。EP087旧熊伤非弱点，EP088「定罪」只知眉心不破甲，EP089医生刀同样失败且熊皮护带被割断，EP090只用既存两组纹发动**一次「处刑」**破额甲、周启同破口补刀。**消耗后的刑纹余态仍未锁定**。

## 五、稳定承接与开放事项

- **已固定**：首批15人最终6死（何雨、吴大勇、孙浩、刘斌、蒋文、魏叔）、六登船（韩震、罗峰、唐梨、许知意、马青青、赵骁）、三留岛（林渊同体、陈七、苏小满）；铁颚死亡后两小时首船离港。阶段二仓库双III甲乙不同实体且都被阿禾击杀，普通III丙仍在岛上。
- **角色能力**：林渊C「共情」仅近距离感到情绪，非读心；陈七只投送亲持实物到亲到且空置的标记点；小满B「灵丝」需要实锚点；阿禾「定罪」知弱点不保证破甲，「罪己」痛和增强并行，「处刑」只用已有纹路。阿禾、阿月不自动共享实时记忆。
- **登记、后果与结局**：医院院长死不消除两名登记；Day15阿禾近三天昏迷、Day18林渊醒来不获得阿禾战斗记忆。阿月的托话只由小满亲自向阿禾交付，不能把人格话语当逝者客观证据；季终船的资格和后续航次未解答。
- **下一次迭代建议**：不要为了“全101集都变动”改动已形成独立抉择的片段。先用两人实演或动作排场**优先验证EP011、012、086、090、091**，在确知时码和地形后，再决定是否需要跨集界移动小段动作，避免靠删台词掩盖动作负荷。
