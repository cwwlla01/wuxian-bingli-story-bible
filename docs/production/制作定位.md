# 《渡己而生》第一季｜制作定位与分集节奏

> 《遗弃之岛》定位为红果横屏16:9悬疑、惊悚、无限流生存AI漫剧。**总集数与单集时长暂不锁定，待完整故事大纲和制作形态确定后按实际容量规划。**本文记录制作定位与工作索引，人物和剧情以[五阶段大纲](../大纲/README.md)、[时间与知情](../world/06_第一季因果_时间轴_知情边界.md)为准。

## 整体视觉方向

- **主风格：** 写实质感三维动画，做当代海岛环境里的生存惊悚与克制科幻；人物比例、表演和日常物件可信，异常感从光线、空间秩序被打破和怪物行为中出现，不把整座岛做成传统废土。
- **参考分工：** 《灵笼》参考大场面构图、工业材质、强逆光与怪物压迫感；《最后生还者》参考普通环境被危险侵入后的生存质感和人物关系近景；《Scavengers Reign》参考生物异质性与生态观察。只吸收视觉方法，不照搬任何作品的角色轮廓、服装、怪物、道具或场景设计。
- **本项目辨识度：** 港镇、仓库、疗养院和林业站保留可辨认的当代用途。疗养院白天秩序洁净、冷静而过度规整；怪异先表现为铃声、空床、病历、动线与查房秩序的异常，再升级为具象威胁。岛屿日照逐步消失，画面也从自然海天色过渡到依靠实景光源的夜间层次。
- **色彩与光：** 日间采用自然阴天海岛色和低饱和现实色，不统一套灰褐滤镜；海水固定为浑浊灰黑、近乎不透光，只留冷灰波纹反光，不做纯黑死面或油污质感；首船是灰白船体、深色水线的中型客运渡轮，生活空间朴素耐用；疗养院以偏冷的白、灰绿和硬质反光建立制度感；完全永夜仍保留手电、灯具、火光和月面反射等方向明确的光源，避免整屏死黑。
- **镜头与制作：** 16:9横屏以清楚的空间关系为先；广角交代路线、门窗和怪物距离，近景捕捉人物五官与微表情。优先复用少量核心地点、用光态和状态变化制造升级，不依赖无法持续生成的大型未来都市、密集群演或过度复杂机械装备。
- **角色与怪物：** 角色沿用人物档案中的年龄、身形、五官、妆造与技能精神来源；能力表现服务人物选择，不变成无代价的炫技特效。怪物保持生物性和各自行为逻辑，压迫感来自尺度、运动和空间位置，不靠无差别血浆堆叠。

## 一、真正的观众承诺

**主题命题：** 每个挑战的表层目标是活下来，内层考验是人在困难中如何选择、逐步看见并成为真正的自己。灵魂升华来自承担选择的后果，不由技能升级替代。

**外层：** 十五个人能否完成任务上船？铁颚被杀后，赵骁背叛导致仓内六人死亡；林渊昏迷，陈七和小满各自能赶上船，却选择留下扶持他，三人因此滞留。团队同伴并不天然可靠。

**中层：** 林渊并不能随叫随到地让S级阿禾代打；Day4三人合力杀**单只I阶骨犬**都险些失败，之后靠周启训练、实地锚点、装备、据点和代价才逐步变强。成长必须可见，不靠单句“练了很多天”。

**内层：** 阿禾为何以疼痛换力量？Day3双III初醒，Day13「罪己」增纹，Day15以「处刑」消耗累积刑纹、破五阶额甲，随后近三天以昏睡为主、Day16与Day17各短暂清醒一次后又沉睡。**Day18小满把岛上阿月人格Day12亲口托付的话交给自愿出来的阿禾**，不把她的爱等同错误，也不能用一句话解释成“治好了”。

**第一季答案：** 五阶鬼院长已死、四人仍在岛上，永久登记和岛屿根因并未揭晓；现实海边新船靠岸后，以意识世界**“林医生，谢谢你”＋焦树新芽**收尾。季终不强加怪物突袭或第二岛预告台词。

**对白声线校验：** 正式写EP001起，每集对照[现行人物档案的表演与压力反应](../world/04_人物档案_分裂人格_十五人名单.md)检查：**说话目的、用词长短、角色已知信息、恐惧下反应、成长阶段**必须匹配。林渊不会像周启那样发号施令，初期小满不应突然硬气得像老兵，阿禾与阿月不应共用台词口气，赵骁不能开场就暴露成脸谱反派。口吻样例用于校准声音辨识度，不当作固定台词；写出角色名后再删掉名字试读，若分不清说话的人就改。

**每集写作闭环：** 目标→阻力→人物实际尝试/改变方法→看得到的结果→代价或新状态→下一集的问题。每集以**一个主要转折**为中心，训练/搜粮/走路/做装备只有让资源、能力、退路、关系、角色知情改变才有资格独立成集。集尾不可只截断一句本该说完的话；终集可以安静落幕。
