# 《渡己而生》第一季｜制作连续性与实操核验

> 本文件用于保存行程、场地、道具、伤势和能力操作方面的制作检查。它不是剧情正史或分场剧本；出现“候选／待核”时，不得当作已确认事实。故事主线与人物选择以[五阶段大纲](../大纲/README.md)为准。

## Day3｜首船倒计时与仓库空间

- **故事硬规则：** 铁颚死亡后两小时游轮离港；望海坡时离港剩25分钟，因此铁颚死亡至上坡有95分钟。
- **未锁绝对时刻：** 12:00离港、10:00击杀仅为预算候选；若路线或行动装不下，调整绝对船钟，不改“两小时”和“剩25分钟”。
- **现场核算：** 仓库至断轨沟的行程、战斗组往返、赵骁引两只普通III入仓并由外部封门、小满折返、三人死亡及阿禾后续脱仓，都需按真实路线核算。
- **仓库结构：** A/B为两处主门，C为中央吊装区，D通北侧维修区，E为检修高窗，F为外部联动闸，G为C西维修侧门。主门的外部联动关系、侧门滑闩、北窗与外侧平台需在场地方案中画清；人物不得瞬移，陈七只投送本人到过并标记的空落点上的非活体物件，小满灵丝不可承受三阶巨鳄重量。
- **第三只普通III：** 沿港口外路追赶登船组，不进入仓库、不新增死亡；后续折返至仓库东侧的路程与时间须连续。

## Day10｜林业站与四小时日照

- Day10日照为06:00—10:00；Day8发现林站与既有工程坑，Day9准备坑边和引熊路线，Day10只能暂困四阶魔熊并占领备用据点，不能把陷坑写成击杀。
- B1—林站往返、引熊、低阶熊分流与清点物资的实际用时尚未验证。白昼不足时调整未锁的前置日程或故事方案，不延长既定日照、不瞬移。
- 林业站的28份基础口粮独立记账；疗养院物资、饮水与林站储备不得混算。

## Day13｜疗养院病床、登记与撤离路线

- Day13真日照06:00—07:00，12:00查房铃仍照常发生。空床异常与既有收治受阻共同引出四阶鬼院长；不得简化成“少一张床就必定召来院长”。
- 陈七与小满完成正式登记后，鬼院长死亡也不注销登记；院墙内的精确感知风险继续存在。
- 二楼窗、维修棚顶、院墙内侧和墙外撤离点的相对位置及承重尚待实测。剧情要求三人确实越墙后再通知阿禾；“跳窗”不等于已经出院墙。
- 周启Day13左肋伤、Day11左上臂伤、阿禾旧刑纹与新增刑纹均须连续；治疗、切换人格不能抹去已建立的伤势和代价。

## Day14—18｜战斗资源与照护连续性

- Day14无日出，全岛怪物整体升一阶；两名原三阶鬼医生升为四阶，鬼院长与魔熊升为五阶。医生越界及其针对登记者的行为仍属未解异常，不由此推出院外常态精准定位。
- 四人击杀两名医生后获得两把手术刀、两颗医生黑晶；声狩晶体按实际检查结果记账，刀盾只取一套；魔熊提供一颗五阶魔晶和一张整皮。熊皮剥取、加工及护甲制作耗时与设备状态需核算，护甲不是五阶防护。
- Day15院长决战：阿禾以「定罪」确认额部弱点，以「处刑」消耗既有刑纹破甲，周启从破口补刀；阿禾严重反噬并昏迷。Day15—18照护需考虑周启旧伤、B1查房、墙外接应、饮水与真实往返，不得默认院长死后医院安全。
- Day18白昼恢复的具体时刻、新游轮靠岸时刻和山路步程均未锁；旧队伍是否可登船仍是后续问题。
