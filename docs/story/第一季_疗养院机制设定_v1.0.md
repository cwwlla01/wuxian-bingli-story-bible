# 《无限病历》第一季《遗弃之岛》｜疗养院机制设定 v1.0

> **机制设定独立入库，2026-11-05。** 依据作者已确认的《疗养院机制设定 v1.0》整理。本文件只记录疗养院运作机制、怪物职责及与第四阶段的已确认衔接；**不改写现有剧情大纲、剧本或日序**。未定项目保留为待设计，不提前锁死。

## 一、核心设定

疗养院是一座仍按照既定规则运行的异常医院。

**医院通过定时查房，识别、抓捕和处置不符合医院管理规则的人员。** 它不是单纯无差别追杀活人的怪物巢穴。

主角团能够通过战斗暂时解决威胁，但**杀死医院怪物会推动医院防御机制升级**，令后续出现的执刀医师增多，并加速院长降临。

## 二、怪物等级与职责

| 怪物类型 | 等级 | 出现位置与职责 | 对未登记人员的处理 |
| --- | --- | --- | --- |
| **值班者** | 二至三阶 | 每次铃响，出现在各层走廊尽头，巡查是否有未登记人员。 | 发现后追捕；抓住则送去登记。 |
| **执刀医师** | 三阶 | 每次铃响，出现在病房内，检查**整个病房**的异常，包括人员、病历、床位及房间状态，**不局限于病床**。 | 发现未登记人员时上报异常、通知值班者处理；**不直接攻击或处置未登记人员**。 |
| **院长** | 四阶 | 当医院怪物累计被击杀达到一定程度后出现，负责抹杀威胁医院正常运行的阻碍。 | 依据是否构成医院运行威胁采取行动，不以普通查房职责处理。 |

**职责边界：** 走廊主要由值班者巡查；病房由执刀医师检查。执刀医师发现病房内未登记人员，无论其站立、坐着、躺卧还是藏匿，均可上报通知值班者；**但不会亲自对未登记人员执行治疗或攻击**。执刀医师对**已登记病人**的异常，则会亲自进行医院规定的处置。

## 三、固定查房时间与结束条件

每天固定四次响铃：

- **08:00**
- **12:00**
- **16:00**（下午四点）
- **22:00**

铃声一响，值班者和执刀医师按各自职责出现并开始查房。**查房由铃声触发，不由白天或黑夜触发**，白天也存在危险。

- **未发现需要处理的异常：** 怪物完成本轮查房后消失，等待下次铃响再出现。
- **已发现异常：** 怪物会继续执行抓捕、登记或处置流程，不能仅靠拖到正常查房结束便让正在处理事件的怪物无条件消失。
- **地下储物室：** 不属于一至三楼病区的**日常查房区域**，可以暂作躲避处，也解释周启此前能在那里长期沉睡；但这**不等于地下室能绝对阻止怪物的主动追击**。

## 四、异常判定与处理分工

| 异常情况 | 发现者 | 处理方式 |
| --- | --- | --- |
| 未登记人员出现在走廊 | 值班者 | 直接追捕，抓住后送去登记。 |
| 未登记人员出现在病房 | 执刀医师 | 上报异常，通知值班者抓捕；执刀医师本人不直接攻击。 |
| 已登记病人出现异常 | 执刀医师 | 直接执行医院相应处置；具体“治疗”方式待后续设计。 |
| 医院怪物被击杀 | 医院整体机制 | 累积危险，增加后续查房的执刀医师数量、加速院长出现。 |

**被发现 ≠ 被抓住 ≠ 完成登记。**

例如苏小满虽被值班者抓住，但阿禾及时救下她，**不代表她已完成登记**。陈七后续进入第十七床并真正完成登记，则成为医院的正式病人，受到针对登记病人的医院规则约束。

## 五、杀怪升级与院长

1. **每杀死医院怪物，都会推动医院危险升级。** 主角团杀怪越多，医院越接近高警戒状态。
2. **后续查房出现的执刀医师会逐渐增多。** 杀怪能暂时清除眼前的威胁，却会提高之后的风险。
3. **院长出现会加快。** 怪物死亡累计达到一定程度后，四阶院长正式出现，抹杀严重妨碍医院正常运行的威胁。
4. **危险升级不随一轮查房结束而清零。** 怪物可以在正常查房结束后消失，但此前造成的升级仍会累积。
5. **院长办公室椅子上凝聚的黑雾**是院长将要出现的早期征兆，**并不等于院长此时已正式登场**。

**暂不设定**精确击杀数量、警戒数值或院长具体能力。

## 六、与当前第四阶段剧情的衔接

以下仅是已确认事件与机制的对应关系，**不在本文件重写剧情大纲或剧本**。

1. **第一晚22:00：** 三人首次真正遭遇查房怪的威胁，受惊撤往地下储物室，在那里唤醒周启。前面白天定时铃声机制同样存在，但三人当时尚未亲眼弄清怪物的刷新规律。
2. **第二天08:00：** 新一轮铃响，值班者刷新，其中有三阶个体。周启被三阶值班者缠住，要求林渊、陈七、苏小满先撤回地下室。
3. **撤退受阻：** 三人到一楼发现多名值班者堵路，被迫转身往楼上逃。小满落后被抓、拖走；在陈七催促及小满呼救后，阿禾第二次接管林渊身体并救下小满。
4. **联手击杀：** 阿禾和周启联手解决围攻周启的怪物，四人得以短暂休息；周启对变成阿禾的林渊好奇，陈七作出解释。众人准备趁怪物暂时清空继续搜寻物资。
5. **黑雾伏笔：** 同时，院长办公室椅子上出现黑雾，暗示主角团大量击杀医院怪物，已经加速更高层级危险的到来。
6. **第十七床隐患：** 陈七后续将遭遇抓捕并在三楼第十七床完成登记，从未登记人员变为正式病人；**具体如何触发及为什么是第十七床，仍待单独设计**。
