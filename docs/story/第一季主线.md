# 第一季《遗弃之岛》｜七阶段主线 v0.7

> 这是现行故事阶段因果，并非已完成分集大纲。红果横屏16:9；单集60—90秒、100—120集仍为工作范围而非定稿。以创作者最新确认覆盖旧 v1.9 长剧剧情顺序。

## 阶段一 登岛、救命、队伍分裂

首批十五人登岛分散探索。生前是高中生的苏小满原本家庭幸福，后来父亲失业、父母争吵离婚，她想弥补父母关系，逐渐敏感懦弱；登岛虽有B级「灵丝」却不自信。她险些坠海，林渊救下，旁边救生圈直接沉底。苏小满长期在黄毛队被使唤做杂务，首日何雨死亡。

## 阶段二 仓库惨剧、阿禾觉醒、三人错过船

九人队杀指定三阶铁颚，吴大勇、孙浩死亡；赵骁另引一只普通三阶封仓，魏叔、刘斌、蒋文死亡，小满亲眼见其中一人被吃。林渊精神崩溃，七彩光柱与脑内钟声中，阿禾第一次接管击杀普通III；小满很崇拜阿禾。阿禾带陈七、小满来到码头，看到海想起和现实阿月一起看海的约定，情绪震动切回林渊。六人登船、三人滞留，开始讨论阿禾及如何变成阿禾。三人的单体战力仅勉强持平一只I阶。

## 阶段三 永夜里的旧仓库

入夜三人回到以前据守的仓库，躲进房间、把门抵紧，听着各式夜声熬过第一段长夜。第二次日光来临，附近村镇物资已经被搜刮得差不多，三人向岛内探索。光照窗口很短，天很快黑了，返路被怪物堵截，他们只能朝山上奔逃。

## 阶段四 院门规则、地下储物间苏醒者、第三夜机制怪

外部怪物在疗养院边界突然停住。三人先靠院墙躲过长夜，随后趁短暂天光进入疗养院，**看见门口旧院规**；他们只看过文字，不知道真有谁在执行。三人在1—3楼小心搜集一些水，起初院内平静。

夜里走廊响起疑似“查房”的脚步与开门声。三人想起入口规则，怕被发现，沿真正的后勤楼梯躲入**B1地下储物间**。在此发现一个不属于首批十五人衣着的男子，先疑怪物再疑尸体。陈七好奇查看，发生**直接活人身体接触**；死眠中的周启瞬间醒来，靠老兵战斗本能和A级肉身**直接将陈七制伏**。双方解除误会后结队。

周启透露：自己来自**上上批**，当年正常任务期间这家疗养院**没有怪物**。他只是好奇自己的A级「不死战躯」，在地下储物间独自尝试，却意外陷入无法自醒的死眠，一直躺在原处。**他并不知道病历规则**，也没有被从地下室搬到三楼；旧“移位之谜”不再成立。三人只能把入口告示、实际脚步与他的历史并列观察，不可能由周启直接给出鬼院长机制的答案。

之后搜物资时小满被怪物拖走，喊“小禾救我”；林渊惊恐与保护冲动促使阿禾第二次接管并救她。小满见阿禾对假发和镜子表现异样、将其收走，模拟阿月不因看到镜子直接出现。**疗养院第三夜**机制怪首次正面出现；此时才根据实际行动验证或纠正此前“查房”的猜测。具体怪物岗位/病历机制仍使用后续v0.5—v0.6工作提案，不擅自锁定。

## 阶段五 周启训练与能力成长

第三夜机制危机之后，周启正式训练三人。林渊改善情绪辨别与团队判断；陈七学会用实体标记与「定点投送」配合；小满渐渐拥有自信，让灵丝真正参与辅助战斗。他们不会一夜跨越战力阶位，长处是观察、布置、撤退和协作。

## 阶段六 东部泵站危机与救回导师

四人遭遇东部泵站四阶巢母污染水源，周启负伤再次进入死眠。后来在鬼院长威胁下，由陈七冒险**再次直接触碰**唤醒周启，小满提供辅助而非替代触碰。此时三人的能力进步必须在场面中发挥真实作用。疗养院失守，队伍退向林区。

## 阶段七 裂谷、告别与下一批来临

缺水迫使四人靠近东南裂谷五阶巨兽活动区，策略是谨慎取资、避战撤离，不是秒杀V。阿禾与她潜意识模拟出的阿月通过错时记录逐渐告别，阿禾选择首次主动使用一直拥有的「忏悔」，林渊回归但不自动熟练S技能。新批十五人登岛，岛屿环境恢复初始废墟模板，四人仍未逃脱。

## 本季贯穿的情感对照

- 小满曾努力弥补父母婚姻；林渊有救人失败的愧疚；阿禾无法放下现实阿月的死亡。三人分别学会**尽力行动，却不能替别人决定结局**。
- 疗养院的层层恐惧：外部怪物止步 → 门口旧院规 → 楼内疑似查房动静 → 躲进地下储物间，周启突然制住陈七 → 第三夜真正见机制怪。
- 周启从最初的强者导师，后期反而需三名学生用训练成果救回自己。
