# 《遗弃之岛》｜第一季七阶段主线
> 仅是阶段因果，不是最终分集规划；红果横屏16:9 AI漫剧。60—90秒/集和100—120集目前为工作提议，尚待作者确认。

### 1. 十五人登岛
船将首批十五人送上海岛；小满险坠海，林渊救援，海水无正常浮力；何雨最先死亡，生存队伍分化。

### 2. 讨伐、背叛与仓库觉醒
九人小队杀指定III铁颚，吴大勇、孙浩死。赵骁引另一只普通III锁仓，魏叔、刘斌、蒋文死。七彩光柱、脑内钟声、高僧点拨中，林渊崩溃，阿禾因小满和阿月相似的脸而出现，杀死普通III。阿禾带陈七、小满至码头见海，忆起与阿月的约定后震荡切回林渊。六人乘船离开，三人滞留。

### 3. 永夜与周启训练
三人遇到来自前两航次的周启。苏小满偶然接触使死眠中的周启立刻苏醒。周启训练三人逃生、分工、配合、独立判断。

### 4. 疗养院与第三人格阿月
四人探索疗养院。阿禾夜间自主化妆，模拟阿月才可能出现；阿月有独立主观意识但非现实逝者复活，也不能使用处刑者。院长（值班者III特殊亚型）带来威胁。

### 5. 东部泵站污染与救周启
IV级巢母污染水源，周启受伤进入死眠。林渊、陈七、小满要靠训练成果救回周启，陈七活体触碰使其醒来，不可写成自醒或复活。

### 6. 据点失守与裂谷
疗养院失守，四人退往南部林区，缺水迫使其接近东南裂谷V阶巨兽领地，重点为隐蔽逃生，不可独立击杀V。

### 7. 告别与岛屿复位
阿禾逐渐接受现实阿月已不在，模拟阿月也不能代替她。通过化妆和间接留言完成情感告别，阿禾主动使用「忏悔」，林渊复归但不能立即熟练用S天赋。岛屿恢复废墟基线，新船送来下一批挑战者；四名主角没有在第一季离岛。

**三大人物主题**：周启教三人活下去；林渊理解自己被封闭的过去；阿禾和阿月关于自我接纳、爱与失去的牵绊。
