# 码头与仓库｜不可颠倒的因果链

## 登岛 D0【已确定】
苏小满险坠海，林渊救她，同时众人了解到海没有正常浮力。

**【工作方案｜可见证据】**：小满在潮湿舷梯/破旧踏板上踩空；林渊抓腕，陈七扶稳林渊；船用救生圈撞落入海竟直沉不浮，众人因此得到直观证据。小满不必真的落水；救生圈、陈七的动作与对白均未定案。

## 仓库 D3【已确定】
九人猎杀队击杀指定III铁颚，吴大勇、孙浩死亡。赵骁**另引一只普通III怪物**困住仓库人员与回来的小满，魏叔、刘斌、蒋文死亡；两只怪物不可混淆。

林渊崩溃，身上多道七彩光柱出现；脑中钟声响起、高僧点拨回荡。小满的脸有几分像现实阿月，联想触动林渊/阿禾潜意识，是阿禾接管同一男性身体的重要原因之一。阿禾以S级处刑者击杀另一只普通III，救下陈七、小满。

**【工作方案｜小满的自主行为】**：她曾用灵丝救人，因锚点/负荷/时限不足而失效；林渊看见她颤抖却不肯丢下同伴的一瞬，产生短暂、不完整的阿月面容闪回。不因小满喊叫就可靠召唤S级人格，也不让她救活三名既定死者。

## D3 阿禾返港与林渊复归【已确定】
阿禾带陈七、小满赶往码头。看到海，她想起与现实阿月关于一起看海的约定，恢复部分相关记忆，情绪剧烈波动，身体控制权转回林渊。六名猎杀队成员乘船离岛，林渊、陈七、小满滞留，随后认识周启。

林渊**没有**自动继承阿禾接管期间的实时记忆，须靠环境与队友口述了解其间发生过的事。

## 世界设定边界
岛上的阿月是阿禾潜意识模拟出来、拥有独立意愿的第三人格，**不是现实逝者复活**；阿月仅由阿禾在夜间完成真实化妆后出现，日出回到阿禾。仓库并不提前唤出阿月。阿禾→林渊的码头情绪切换不代表S级能力被林渊立即掌握。

## 与苏小满成长线衔接
周启后来训练苏小满使用实体锚点、短时灵丝牵绊和警戒，初始失败会在后期“救周启”事件中产生可观察的回报；后期陈七亲自触碰周启使其从死眠中醒来。详见 [苏小满成长账本](苏小满_成长节点与伏笔账本.md)。
