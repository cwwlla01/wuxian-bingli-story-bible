## 使用约束

1. **同名不等于不同个体**：农林区、林业站两栏的「魔熊」是地区分布描述；原四阶魔熊被困、Day14升级五阶、与鬼院长交战而死亡的主线不变。
2. **Day13—15的剧情换名不换因果**：鬼护士／鬼医生／鬼院长分别对应原值班者／执刀医师／院长；两名鬼医生的手术刀仍由阿禾、周启各持一把；「定罪」识别前者颈部弱点、后者鬼院长眉心弱点，最后鬼院长仍需「处刑」破额骨甲。
3. **旧普通鳄类细分怪物正式移除**：不再单列任何额外的普通鳄类物种，旧剧情中承担追击、占据仓库等作用的普通鳄形怪统一称为**「巨鳄」**，但其原有数量、阶位、位置、击杀与伤亡账保持不变。系统指定三阶BOSS**「铁颚」**保留为专名，与普通巨鳄的具体物种关系暂不扩展。
4. **“夜巡者”不推测改名**：此项没有指定替代名称，继续使用「夜巡者」直到作者另有指示。
5. **历史文件**：已经完成的旧工作剧本与曾经的旧版本大纲保留历史上下文，但在最新创作、修改和对外制作文本中，应以本表为最终命名依据。
