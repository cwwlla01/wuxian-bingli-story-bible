## 一、戏剧承诺与硬边界

问题：林渊精神崩溃、双III已入仓，阿禾首次接管是否真的能连杀两只？在游轮离港前他们是否有机会赶到？**第二阶段的答案**：阿禾以真实的空间利用、战斗代价和S技能击杀两只独立三阶怪物，带队逃出；**山坡见海触发回切**，林渊受创后无法正常赶路，陈七和小满若抛下他或可赶船，却都选择陪伴；三人错船，系统宣布岛屿状态改变。

- 阿禾、阿月与林渊共用**同一具男性肉身**，同时只有一个主控；首次换成阿禾时发型、发色和眼眸颜色可见变化，**不是性别变身或长出另一具女性身体**。颜色具体色值和发型细节留美术设定统一，不能随意每场变化。
- 生理伤势、疲劳、既存刑纹与痛感不因主控切换而消失。外貌变化不改变身体体格、衣物、可使用工具或现场空间。阿禾不继承林渊缺席时以外的即时记忆，不会自动知道仓库平面。
- 阿月**本阶段不出现**，没有夜间真实装扮仪式不能触发；阿禾S「处刑者」非C共情升级，五技能仍受既有边界制约。
- 仅有指定III「铁颚」被讨伐队所杀；仓库两只均为不同实体的普通III裂鳄者，绝非铁颚复活或48小时刷新体；此处两只都必须在镜头中**有各自可验证的死亡证据**。
- 小满在旧检修道路亲眼见赵骁引**两只**入仓并在外侧拉闸关闭两侧主门，必须沿真实道路跑回；她不能突然出现在仓库里或凭灵丝吊起三阶怪物。
- 陈七C「定点投送」只能投送非活体、到本人先亲赴实地标记的空落点；这不是战胜两只III的万能机关。
- 阿禾在山坡见海时脑海闪出模糊回忆画面，并清楚响起一句「等我们以后有钱了，就一起去海边看海吧」；这是她与现实阿月看海的约定和有限主观记忆，不能顺带揭露全部人格真相。回切林渊发生在**能望见大海的山坡**，不是码头。
- 赵骁主动封门与林渊前序人际崩溃仍按第一阶段V4.2已写的事件承接；仓库旧三死不复活。初醒的七彩光柱、寺钟与高僧旧话保留。

## 二、仓库建筑——先有场景，再有打法（均为【工作美术／动作方案】）

定位：废镇边缘**旧货运冷链＋维修综合仓库**，曾为附近矿区／铁路备件、食品冷柜与机械运输服务。其重型设施均有旧用途、腐蚀损坏及承载限制；第三天不是临时从空气中生成机关。

| C 中央货梯井／旧吊装区 | A与B之间，水泥基座、限位钢轨、笨重但可移动的旧升降台、维修止挡销与原本运送重货的压梁 | 第二只III的危险战斗地点：借其冲撞与**受损承重机构自然失稳**形成压制窗口；不能只按一个按钮就凭空砸死怪物 |
| D 北冷库夹道 | 货架侧道、厚内隔火门、维修小屋与旧工具柜 | 双III可从不同实体通道包抄；后半段用于撤退和击杀后的寻找出口 |

**平面行动关系**：山道／铁路 → B东坡道 → C吊装区 → A西大厅／港口方向；北侧D冷库夹道通E检修高窗。两个III可穿B—C—A及B—D—A不同走廊夹击；追击、转向与伤亡须逐镜头画路线。小满从仓外高坡经维修道跑到E的外平台，不能直接越过高窗到阿禾身边。

**首幕预埋的实物线索**：D1清理仓库时镜头看到锈钢索、旧吊台止挡销、粗大铁笼、重货轨、北检修窗、外侧双门闸；魏叔／陈七盘点并实际摸过某些工具，陈七实标一个可接收**小工具**的空石台。若这些前置镜头尚未补拍／补写，第二阶段不能把它们当观众理应知道的装备。

## 三、两只三阶的真实击杀设计

**第一只III：依靠阿禾S能力的首次近身成功，不是货架砸死。**

1. 阿禾首次显身后确认靠近的第一只III从北夹道进来，同时发现另一只仍在中央吊装区；短时争夺D夹道空间。
2. 阿禾用短刃作实体接触并试探「定罪」所得可攻击的关节／颈甲连接处；第一次刺击被骨甲偏转，她被迫后撤，处刑反噬痛让手指发颤；**没有实体战伤**，观众看见S不是自动结算。
3. 陈七用先前魏叔工具包内的真实楔子卡住夹道侧门，使第一只猛冲时失去半拍节奏；这只是**创造短促窗口**，不封死怪物。
4. 阿禾借身体转位逼近，**第二次实体命中后发动「行刑」**，以明确伤口／倒地失去生命体征的视觉确认第一只死亡。刑纹出现／旧伤加剧，阿禾呼吸、握刀力与奔跑能力受到代价。

**第二只III：重型仓库设施＋实体近战，再一次冒险杀死。**

1. 第二只从中央吊装区撞开斜隔板追来。阿禾试图照第一只的方法直接处理，但它正面骨甲更厚，而且阿禾身体已有刑纹反噬剧痛与精神疲惫，第一次交锋失败。
2. 苏小满终于赶到**E外侧平台**，从检修口看见货梯井旁的残损卷扬连杆；她的灵丝只牵动**小型止挡销**，无法凭空启动无动力货梯，也不直接绞死怪物。陈七按阿禾目视指示使用早已到过的标记台转送一枚实有小钢楔，辅助卡住将要回弹的轻锁扣，**两人承担真实风险和代价**。
3. 阿禾不逃进狭死角，刻意使第二只追向C吊装区**已经因早期战斗损坏的升降台边缘**。它自身惯性撞歪承重导轨，阿禾趁它冲撞时扯掉原本支撑的旧销，借实际存在的**重货配重／台面下坠**压住其一侧前肢，争取极短的可攻击姿态；重量、行程、落点必须在分镜时测算，不能保证永久困III。
4. 第二只仍剧烈挣扎、将要挣脱，阿禾只能拖着旧伤实体近身，把短刃送入「定罪」找到的头颈连接处，使用第二次「行刑」完成致命攻击。她付出**明显高于第一只**的刑纹痛、肩伤、失力代价，不能仍健步如飞。
5. 镜头核验第二只身体停止动作、伤口与配重位置；不是怪物消失或自行离开。两只尸体后来仍存在，直至符合48小时补充机制（不在当场立刻刷怪）。

> **制作风险提示**：连续两次三阶处刑强度较高，具体S技能负担（刑纹、能耗、器官反噬）必须与既有`05_天赋技能`条款再核对；若与旧上限矛盾，动作与代价需调整，不能擅改S能力上限。起重设备必须是**无电或仅依机械重力可以运作**的旧结构，不能假设废岛突然通电。

- **时间核算**：作者新定**山坡回切时系统离港倒计时25:00**。指定铁颚死后「一小时后离港」需在前35分钟内容纳怪物追逐→封仓→仓库三死→阿禾连续双III战→实路上坡；后25分钟实演「背人须绕运货坡路」→游轮离开→抵码头；**不得仅因集数扩为8集便让岛内实际时间自动增加**。如按预演时间不够，需要缩短物理路程并核对危险概率，或把「一小时」列待作者另定。


## 六、2026-11-04 作者最新确认：码头醒来与返仓告别（覆盖冲突叙述）
