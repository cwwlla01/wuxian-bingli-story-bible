# 《医生也会被收治》｜疗养院智斗事件 v0.5

> 【工作方案】本事件沿用创作者最新提出的三层医护分工；不是正式定稿，也不改变第三夜由值班者初次出现的事件顺序。下列动作、台词与具体程序均为编剧待审方案。

## 事件定位与核心承诺

建议安排在第三夜之后、三人经过初期训练、开始接触治疗区时。第三夜先展示值班者会抓捕和运送清醒者；本次让观众第一次看见**执刀医师对病历的偏执**，再展示**院长对医护也严格问责**。

- **行动目标**：小满和林渊要把陈七从治疗室救出来。
- **阻力**：陈七被错误分配到17号床，旧病历记载的身体状态与陈七现状不符；II阶医师仍准备按病历启动治疗。
- **转折**：小满发现医师未经确认患者身份和床位记录，找到实际登记材料；院长到场完成实地核查，判定医师违规并开始处理。
- **回报与代价**：院长转而处理违规医师，队友趁短暂空隙解除陈七身上的固定、撤出治疗室。陈七仍存在登记风险，队伍失去原定搜集的物资，也没有获得正式出院。

## 前置可见伏笔

1. 小满曾在护理站看到医护内部规定：**“诊疗前，必须完成患者身份及床位核对。”**
2. 护理站留有实体床位登记簿和病历卡，允许角色观察**床号、临时腕带编号和原患者身份**是否一致。
3. 总查房并非小满召唤。院长因其他实际记录冲突、转运混乱，经医护回报后启动巡查；胸腔共鸣响起，值班者沿实在的走廊重新集结。具体启动阈值尚待定。

## 重点场面（局部剧本）

### SC01 INT. 疗养院二楼治疗区 / 夜

△ 值班者将陈七带到第17床，用临时腕带记录床号。床边放着一份纸张泛黄的旧病历。

△ 执刀医师拿起病历，靠近陈七作实际检查，发现病历记录的状态与陈七目前的状态不符。

陈七：你们找错人了！我不是这张床原来的病人！

执刀医师：诊断正确。

△ 它将病历翻至下一页，准备开始所谓的“矫正”程序。

执刀医师：患者状态错误。

△ 陈七想挣脱，却无法独自离开治疗床。

### SC02 INT. 二楼护理站 / 连续

△ 小满在护理站查到：临时床位单上写着“17”，但患者身份核验一栏空缺；旧病历的记录却属于另一个编号。

苏小满：它没有核对人是谁，就准备治他……

△ 她抬头，看见墙上那条术前核对规定。听到远处院长总查房的共鸣，她意识到这可能是目前唯一的机会。

△ 她与林渊将两份实体记录放在院长即将经过的核验台上，自己承担被发现的危险。周启在另一端留出撤路，并防止值班者从身后截断退路。

### SC03 INT. 二楼治疗区 / 连续

△ 院长抵达。它先检查17号床的旧病历，再确认临时腕带没有完成身份核对，最后看向已经启动诊疗准备的执刀医师。

院长：诊疗流程错误。

△ 医师停下动作。院长胸腔发出短促共鸣，临近的值班者实际走进治疗区。

院长：医务人员违规。

△ 医师后退；院长与值班者开始执行对违规医护的强制收治。

院长：立即收治。

△ 在医护注意力转移的短暂时刻，陈七配合林渊与小满解开实际束带，周启护住退路。几人撤离，却听见院长仍在命令值班者核对病床登记。

### SC04 INT. 后勤楼梯 / 连续

陈七：医生也会被院长抓？

苏小满：它认的是程序，不是自己人。

林渊：但你的登记还在他们手里。我们只是暂时逃出来。

△ 走廊深处再次传来脚步声。四人不再回头，沿着已经探查过的后勤楼梯撤离。

## 因果审计

- 总查房有**可见前因、医护回报及胸腔共鸣预警**，不是院长凭空出现。
- 小满必须让院长实际核实记录与违规治疗准备，不能凭一句举报使医师立刻失效。
- 执刀医师被处理时，陈七仍须自行或由队友实际解开束带，不能因为怪物之间问责就自动松绑。
- 院长问责医生是**组织行为**；不能将其写成一套远程秒杀法术。其他值班者还可能继续追捕。
- 正式出院仍要求**全部诊疗完成、无待处理异常、院长签字**；成功逃出治疗室绝不等于已完成出院。
- 第三夜“推床抓人”建议归入**值班者**职能；医生只在本案或后续才展示病历矫正，院长不是加强版医生。
- 旧病历从何而来、为何陈七被错配、院长接报触发门槛，以及这招为何只有一次成功机会，都须在正式分集里有可观察证据。
