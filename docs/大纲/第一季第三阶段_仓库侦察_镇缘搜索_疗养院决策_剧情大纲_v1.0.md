# 《无限病历》第一季《遗弃之岛》｜第三阶段剧情大纲 v1.0

> **阶段级入库，2026-11-05。** 依据本轮作者讨论确认的事件顺序整理。**只定剧情骨架，不拆分集、不写场次台词、不锁具体分钟与食水数量，不替换现存剧本，也不调整第四阶段。** 未经作者另行确认，不自动扩展院内怪物机制与疗养院异常线索。

## 阶段定位与日序

- **Day3（首轮BOSS铁颚战、错过游轮日）**：林渊、陈七、苏小满回到旧仓库。仓库**还有口粮**，但外围怪物活动日益增多。三人暂借仓库休整、度过错船后的第一夜，而不是因为断粮被迫立即弃仓。
- **Day4（本阶段主要剧情日）**：三人趁有日光，**外出侦察能否找到比仓库更合适的长期据点**，顺便补充物资。出发时尚未确定要永久放弃仓库。
- **Day4夜间（阶段收束）**：三人经地图选择向山上疗养院侦察，抵达其外围后谨慎落脚；**Day5清晨正式进入疗养院属于第四阶段的开端**。不在本纲继续展开院内剧情。

## 主要剧情因果链（本轮作者确认方向）

1. **有粮但不宜久守**：仓库仍留有可用口粮，危险来自外围怪物增多与据点长期防守的不确定性。三人决定白天侦察更好的住处，并为实际路程携带简单武器、少量必需物资。
2. **一阶骨狼伏击，三人首次真正协同击杀**：路上遭遇**一只一阶骨狼**。苏小满利用周围障碍布设**灵丝陷阱，短时间绊缠／限制骨狼扑击**；陈七与林渊抓住机会，用手中简易武器协力**杀死这只骨狼**。灵丝提供战术窗口而非永久控住怪物，不靠阿禾自动出现解决。
3. **镇子边缘探索**：三人抵达小镇外缘，搜索一些可进入的建筑，取得**少量可携带物资**，并**发现一张标有山上疗养院位置的地图**。地图是普通地理信息，并无异常传闻、提示或隐藏邀请。
4. **怪物聚集迫使改变搜寻方式**：他们从镇边发现**多只巨鳄，以及向这一带游荡的二阶怪物**，判断此时深入镇内不划算，不主动挑战怪群。暂不替作者认定所有巨鳄均为二阶，也不把旧仓库已被阿禾击杀的怪物写成复活。
5. **沿外缘撤退并适量搜集**：三人避开怪物主要游荡的区域，沿退路绕过**几处边缘房屋**，在安全允许时继续收集可背负物资，随后**撤出小镇**。不是发现二阶怪物后又无理由返回镇中心。
6. **地图讨论后决定上山**：撤出后对照地图共同商量，认为疗养院**可能有药物、日常物资，以及适于暂作据点的建筑空间**。三人选择去看看，保留“只是侦察、未确认安全”的判断，**不是被怪物一路追进医院，也不是被传闻诱导过去**。

## 本阶段人物与风险价值

- **苏小满**：第一次在三人组的关键战斗中真正发挥灵丝陷阱作用，不再只是被保护的一方。
- **陈七**：抓住陷阱形成的时机，与林渊协同用实体武器完成击杀，开始形成主动配合。
- **林渊**：即使没有阿禾主控，也能和同伴一起应付力所能及的威胁；仍不能随口召唤阿禾。
- **三人共同策略**：能战的低阶危险尝试协同解决，**见到多怪及二阶压力就避让、撤离**，从而主动选择新的探索目的地。

## 与第四阶段的明确边界

- **进入疗养院之前，三人没有听过任何关于它异常的传闻，也没有取得任何异常线索。**
- 不安排“怪物到了疗养院围墙突然停住”“院外先出现灵异现象”“地图指示神秘病房”等预告式桥段。
- 三人上山目的只有**寻找药品、物资、潜在新据点**；院内危险及旧院规的真实意义，留到**正式进入后的第四阶段**逐渐发现。
- **保留讨论开放项**：外围搜到的具体物品、骨狼战斗损耗、房屋与道路的地理细节，等将来讨论该阶段剧本时再定；**本次不为这些未讨论事项新增设定**。

**一句话主题：三人在没有阿禾直接帮忙的情况下，靠协同战斗和理性撤退，找到下一处值得侦察的生存据点。**
