## 二、已确定的重要跨阶段规则

- 头一批是15名挑战者，Day3首船离港后林渊、陈七、苏小满滞留；周启后来在疗养院B1与三人汇合，形成四人队。
- Day3日出为06:00，日照逐日缩短；Day14进入完全永夜、怪物整体升阶；Day18白昼恢复，有下一艘游轮靠岸。**船抵港并不等于旧四人可以立刻登船**。
- 阿禾是林渊共身的S「处刑者」，「定罪」识别弱点、「罪己」对自身处刑并产生刑纹、**刑纹存在期间持续疼痛并持续提供战力增幅**、「处刑」燃烧刑纹造成攻击及反噬；旧「忏悔」候选不作为当前已锁机制。
- 阿禾与现实中的阿月曾为恋人，遭村人与家人非议、逼婚后分离，**现实阿月死于自杀**；岛上的阿月人格并非简单等同于逝者灵魂，阿禾何以出现在林渊体内待后续揭晓。
- Day12阿月第三次实际现身时托小满转告“她不怪阿禾，认识她很开心”；Day18现实海边转述后，**最后切意识世界**：阿禾坐在焦树新芽旁说“林医生，谢谢你”，林渊无言微笑。
- 巨鳄、缝声人、鱼人、鬼护士、鬼医生、鬼院长、骨犬、魔熊、巢母、渊骸巨兽、夜巡者等使用正式名称；**旧普通鳄形怪细分称谓已移除**，指定首轮三阶BOSS「铁颚」仍保留专名。
