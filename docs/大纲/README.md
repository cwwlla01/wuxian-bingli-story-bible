# 《渡己而生》第一季《遗弃之岛》｜故事阶段总览

本篇按人物选择与故事转折划分五个主阶段，从登岛、错船推进到完全永夜与季终。阶段不按固定集数切分；旧文件名及EP编号仅用于定位内容。

本目录只保留总体与故事线大纲，不包含分场、镜头调度、对白和制作执行方案。

**阶段边界：** 第一阶段将原先分开的登岛、背叛与阿禾初醒合并至错船，形成完整开局弧；第四阶段止于Day13夜间逃院，Day14没有日出只在第五阶段呈现一次。EP编号仅作资料定位，不锁总集数、阶段容量或最终拆分。

**怪物识别规则：** 参与者直接看见怪物本体的任一部分（包括局部或远处轮廓）时，视野短暂显示【正式名称·当前等阶】；完全被墙体等遮挡或只听见声音时不触发。个人图鉴按实际遭遇、观察与战斗逐步记载，不开放全怪物百科、致命弱点、必掉晶体或全图怪位置。指定铁颚任务身份须现场确认，阿禾专属S「定罪」负责发现目标致命弱点。规则全文见[09｜怪物识别与渐进图鉴](../world/09_怪物识别_渐进图鉴_现行机制.md)。
