# 《渡己而生》第一季《遗弃之岛》｜疗养院与林业站阶段工作索引

本索引包含新阶段结构中的第二阶段后段、第三阶段与第四阶段工作条目：EP039—046为疗养院初入与四人结队；EP047—060为医院规则与双据点建立；EP061—074为医院失控、登记与逃离。Day14无日出从EP075起归入第五阶段，不在第四阶段重复呈现。

## 第二阶段后段｜入院与四人结队（EP039—046）

| 集 | 工作标题 | 本集剧情与结果 | 集间交接 |
|---|---|---|---|
| EP039 | 十二点以后 | 三人于Day5午间查房结束后进入疗养院，在餐厅取得少量食水并读到固定查房时刻。 | 首次接触院规，但尚不理解医护职责与登记机制。 |
| EP040 | 空着的病床 | 三人查看病区与楼层，发现异常空床和地下储物室里的疑似尸体，仍未确认其性质。 | 他们暂以B1作为藏身处，医院内部规则仍不明。 |
| EP041 | 四点有人查房 | 16:00查房时鬼护士挡住正门方向，三人只能退回B1。 | 院内道路受巡查控制，外出计划被迫中止。 |
| EP042 | 地下室不是出口 | 三人检查通风栅、竖管与地下室门路，发现B1没有可供人通行的隐蔽出口。 | 他们决定先观察查房规律，不再把地下室当作逃生通道。 |
| EP043 | 十点的铃 | 22:00铃声再次引来楼上动静，三人确认夜间查房同样持续。 | 他们只能在有限遮蔽中等待天亮。 |
| EP044 | 从死里醒来的人 | 三人接触到周启并将他从自愿死眠中唤醒；他说明自己来自更早一批挑战者，却不了解如今的医院异变。 | 新成员加入，但现行规则仍须由四人亲自验证。 |
| EP045 | 别把她带走 | Day6 08:00鬼护士抓住小满，尚未完成登记；林渊因救援压力非自愿切换为阿禾主控。 | 小满被困，阿禾与周启必须立即救人。 |
| EP046 | 四个人的第一战 | 阿禾与周启联手救回小满并处理眼前医护威胁，四人首次作为团队协同行动。 | 院长办公室出现黑雾，医院异常仍在扩大。 |

## 第三阶段｜医院规则与双据点建立（EP047—060）

| 集 | 工作标题 | 本集剧情与结果 | 集间交接 |
|---|---|---|---|
| EP047 | 十二点换了个人 | 四人观察12:00查房，只确认白大褂人员会检查病历夹等现场行为，没有据此推断登记规则全貌。 | 团队开始依照亲历证据认识医院，而不把未知机制当成事实。 |
| EP048 | 裂开的镜子 | 阿禾在旧活动室发现长发假发与裂角手镜，触发模糊的个人记忆。 | 道具成为阿月人格夜间现身的必要前置。 |
| EP049 | 不能让别人一直救 | 周启带队进行有限训练，陈七与小满逐步练习协作；阿禾仍承受刑纹疼痛。 | 团队有所成长，但尚不足以正面应对高阶威胁。 |
| EP050 | 原来的刀位 | 四人前往镇南铁器铺取得各自武器，发现周启旧记忆中的刀位再次出现相似匕首。 | 物资是否随批次重置只形成疑问，未被证实。 |
| EP051 | 这次轮到我们 | 陈七与小满首次协作应对落单一阶骨犬，以实际武器与能力配合完成击杀。 | 两人从被保护者转为能承担部分战斗的队友。 |
| EP052 | 天亮只剩七小时 | 四人继续补充食物并开始规划第二处退路，日照缩短使远行代价增加。 | 林业站成为新的探索目标。 |
| EP053 | 熊占了房子 | 四人发现林业站和成群魔熊，判断无法直接夺取据点。 | 他们开始寻找可利用的地形与撤退方案。 |
| EP054 | 坑比刀有用 | 小队发现既有工程坑与林业站外围路线，转而考虑利用地形暂困高阶魔熊。 | 陷坑方案仍需准备，不能视为已解决熊群。 |
| EP055 | 先算怎么退 | 周启提出备用据点的必要性，队员评估熊群与撤退路线，先制定有限目标。 | 计划从引开低阶熊、准备退路开始，而非消灭整群。 |
| EP056 | 六只先走 | Day9小队驱离部分低阶熊并准备陷坑，未能夺下林业站；夜间返回B1。 | 备用据点计划留待次日继续，阿禾具备夜妆道具。 |
| EP057 | 她说阿禾出门了 | 阿禾在真实夜妆后首次以阿月人格主控，与小满、周启、陈七建立初步关系。 | 阿月的人格边界与阿禾次日回切仍未解释。 |
| EP058 | 大的掉下去了 | Day10周启利用前一日准备的工程坑暂困四阶魔熊，队伍没有将其误判为击杀。 | 熊群仍有威胁，夺取站点尚未完成。 |
| EP059 | 第二扇门 | 四人驱离站边余下的低阶熊，确认林业站可作备用据点并核对现有物资。 | 主休息点仍是疗养院B1，林业站不等于永久安全。 |
| EP060 | 我只是普通人 | 阿月第二次夜间现身，与队友建立更直接的关系，并表明自己没有战斗天赋。 | Day11日出后由阿禾回切，双方不共享完整夜间记忆。 |

| EP065 | 她说从来没怪过你 | 阿月第三次夜间现身，向小满托付一份关于不责怪阿禾、珍惜相识的心意。 | 小满暂不转达，等待阿禾能够自愿听取。 |

| EP069 | 院长下楼了 | 鬼院长下楼攻击，周启与阿禾无法压制；鬼护士从侧路抓走陈七和小满。 | 两人被押往二楼，登记尚未完成。 |
| EP070 | 两份病历 | 陈七与小满分别被正式登记；阿禾以「罪己」承受新刑纹、为周启争取救援时间。 | 登记成为持续威胁，周启必须独自上楼救人。 |

| EP072 | 还隔着一堵墙 | 三人跨越院墙与阿禾会合，四人逃离疗养院；鬼院长存活，主据点失守。 | 登记没有解除，团队不得返回院内长期驻守。 |
| EP073 | 我们攒的十五天 | 陈七与小满短暂试探回院，确认医护仍能感知登记者；四人放弃大部分囤粮。 | 生存物资减少，队伍必须离开熟悉的据点。 |
| EP074 | 有人在叫阿禾 | 四人夜行前往林业站，避开声狩并遭遇缝声人模仿，最终抵达备用据点。 | 阿禾因旧刑纹、伤势与消耗昏迷。 |
