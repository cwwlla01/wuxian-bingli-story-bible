# 《渡己而生》第一季《遗弃之岛》｜第一阶段（下）：阿禾初醒至首船错失

> **结构方案，不拆集。** 本篇承接仓库三名留守者遇害、林渊崩溃、陈七与小满仍在仓内，及两只普通三阶巨鳄尚未解决的局面；经历阿禾首次接管、仓内脱险、望海回切与主动错船，完成第一阶段的开局弧。

## 阶段主线

赵骁的选择让林渊连续失去身边的人，也把陈七和苏小满逼进仓库绝境。林渊崩溃并失去主控后，阿禾首次接管同一具身体，依靠自身技能与陈七、小满的协作击杀仓内两只普通三阶巨鳄。三人离开仓库后，望海触发林渊的主控回归，他随即昏迷。陈七与小满本可先赶往码头，却选择带着林渊同行，最终错过离港游轮。首批六人离岛、三人滞留，求生目标从完成任务转为寻找下一处可靠落脚点。

## 故事线

1. **接住仓库里的失败现场。** 林渊因刘斌、蒋文、魏叔接连遇害而崩溃；陈七还在设法带他脱离两只三阶巨鳄的追击。小满从外侧检修路折返，在仓库北侧高窗附近向陈七传递赵骁亲手引怪、封仓的目击信息。她的证言让陈七知道仓门不是意外失灵，也让观众确认赵骁的选择，但林渊此刻无力处理这份背叛信息。
2. **阿禾第一次取得主控。** 眼前威胁继续逼近，林渊已无法行动，身体由阿禾接管。她与林渊共享身体、伤势和疲劳，但不是林渊获得新能力；阿禾有独立意识，也不自动继承林渊的完整记忆。她先确认陈七、小满及两只怪物的实际位置，再决定战斗与撤离顺序。
3. **第一次击杀建立阿禾的能力代价。** 阿禾主动使用S「定罪」发现其中一只巨鳄的致命软处，但知道弱点并不等于能轻易命中或破防。她以「罪己」生成刑纹，承受真实疼痛并获得持续战力增幅；陈七用定点投送完成有限支援，小满以有实体锚点的灵丝牵动轻小物件。三人合作击杀第一只，阿禾的身体代价和各自的能力边界同时落地。
4. **第二只巨鳄迫使三人继续协作。** 第一只死亡没有让仓库立即安全，第二只仍能沿仓内通道追击。陈七、小满分别处理能由自己承担的阻碍与撤离准备，阿禾再次找准机会击杀第二只。仓内直接威胁解除，但阿禾的刑纹仍在，疼痛与增幅并存；陈七不能投送活人，小满的灵丝不能承受巨鳄重量。三人最终借北侧高窗脱离仓库，不把逃生结果归功于技能瞬移。
5. **离开仓库后继续赶往港口。** 三人沿可行路线离开仓库，行至能够望见海面的山坡。沿港路撤离的五名同伴已在前方，赵骁也正赶往码头；仓库中的战斗和撤离持续消耗离港倒计时。
6. **望海触发主控回切，林渊随即昏迷。** 阿禾看见海面后，现实记忆被触发，主控回到林渊；他没有获得阿禾战斗期间的共享记忆，身体却承接着持续疼痛、伤势和疲劳。林渊无法独自行动，距游轮离港只剩二十五分钟。
7. **陈七与小满主动选择不丢下林渊。** 两人都明白，若立刻独自赶往码头，也许仍能争取登船；但林渊昏迷，留他在山坡或把照护责任推给对方都意味着将他置于危险中。两人决定共同带林渊前往码头，不把错船写成单纯迷路、跑得慢或被动耽搁。
8. **六人离岛，三人留下。** 赵骁、韩震、罗峰、唐梨、许知意、马青青登上游轮离开；陈七、小满带着昏迷的林渊抵达时，游轮已经离港。首批挑战者结果确定为六死、六人离岛、三人滞留。系统随后宣布岛屿封印解除和日照开始递减；不额外解释系统来源或未揭露的岛屿规则。
9. **滞留者回到已知据点，接受新处境。** 林渊醒来后，陈七和小满分别转述仓库背叛、阿禾接管与双杀中自己实际知道的部分；林渊不凭空获得阿禾的战斗记忆，小满所见的赵骁封仓也需由她亲口说明。三人回到已经清理过、仍有物资可用的仓库，准备在失去首船后重新寻找生路。

## 阶段结果

- **人物状态：** 阿禾首次主控并以持续疼痛换取战力；林渊回切后昏迷，醒来时不共享阿禾的战斗记忆。陈七与小满共同承担照护选择，关系从临时同伴转为主动结队。
- **事件结果：** 仓内两只普通三阶巨鳄被阿禾击杀；铁颚任务已完成，但首船离港，赵骁等六人离岛，林渊、陈七、小满滞留。
- **信息边界：** 小满亲眼看见赵骁封仓；陈七和林渊只有在听她转述后才知道。陈七亲历仓内战斗，可报告阿禾接管和双杀结果；林渊不自动获得其过程、阿禾主观感受或具体技能操作。
- **下阶段承接：** 三人返回仓库后，仍要面对第三只普通三阶巨鳄沿港口—镇区—仓库活动带折返带来的威胁；他们需放弃仓库，依靠记忆和自绘路线继续寻找安全去处。
