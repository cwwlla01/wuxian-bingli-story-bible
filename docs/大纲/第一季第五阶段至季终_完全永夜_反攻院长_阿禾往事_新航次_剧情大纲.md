# 《渡己而生》第一季《遗弃之岛》｜第五阶段：完全永夜至季终

本阶段从Day14没有日出开始，覆盖至Day18。完全永夜后，四人应对整体进阶的怪物，击杀两名四阶鬼医生，并在魔熊与鬼院长交战后寻找反攻机会。团队返回疗养院击败五阶鬼院长，阿禾因「处刑」反噬陷入昏迷。昏迷中，她重新面对与现实阿月相爱的过往、断联与失去；Day18林渊醒来后，众人离开医院，阿禾在山坡听见小满转达的心意。季终落在意识世界中的感谢与焦树新芽；新一批挑战者的到来留待后续航次。
