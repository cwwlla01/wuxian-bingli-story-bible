# 院务档案 017｜床位病历与双红交班 v0.6

> **状态：编剧首选【工作提案】，不是作者已锁定的正史。** 作者授权我自由思考并采用特别形式展开，因此本文使用“疗养院内真实存在的档案复刻＋编剧密封注释”呈现。作为 v0.5 三职能机制的进阶提案，不取代旧版历史设定；以后仍以作者最新明确决定优先。

# 第一封套｜床是主人，不是患者

**拟定的院内思想**：

“病人会离开，床不能没有病历。”

这座疗养院的普通病历并不首先围绕来者的真实身份建立，而是围绕**既有床位档号**流转。原患者早已不在，留在床头、护理站与医务柜里的仍是旧档：床号、历史诊断、旧疗程、待办清单。新来的挑战者如果被鬼护士分配到一张**有档案的床位**，就被送入旧病历的诊疗工作流。

这产生一种不需“医院建筑自动改变身体”的恐怖：医生认为**纸面诊断正确，新人身体错误**；真正伤害必须经它近身检查和具体治疗动作发生，过程可被反抗或打断。

**拟议档案表层来源**：原疗养院留下的旧实体病历、原患者的信息与旧交班薄；什么人最初被收治、旧岛民为何消失、病历为何能伴随航次复位出现，仍是更深的历史悬念。不能断言每位挑战者现实里曾是病人，也不需要系统即时为每个人造纸。

## 档案B｜临时占床登记（剧中可见）

| 栏目 | 当次记录 |
|---|---|
| 临时患者号 | C-07 |
| 被安置床号 | 3F-017 |
| 入床记录 | 鬼护士当场登记 / 夹上真实腕带 |
| 身份与旧档匹配 | **未完成** |
| 医师术前核验 | **未签署** |
| 患者身体状态 | 视力正常，需近身检查才能确认 |

**两类错误要区分**：

- **成功完成身份/床位核验后却出现病历与身体差异**：按这家疗养院的扭曲逻辑，医师会把差异当成矫正目标，这才是制度本身最可怕的日常。
- **像本例这样身份还未核验、医师就开始诊疗**：属于**流程错误**，满足鬼院长将来医疗问责的材料前提。鬼护士如果分错床，也可能一并受审；不能只因为戏里想处罚医师就强行免除鬼护士责任。

本院没有能瞬间精准读出人类名字、病史、灵魂的建筑扫描器。所有判断需要真实看见人、看见病历或由当班医护把记录交到相应位置。

# 第二封套｜空床为什么能藏人

【工作定义】正常查房只按**激活的床位档案与交班任务**核对；尚无病历的空床没有被列入“该被带去诊疗”的日常工作清单。所以未登记者躺在真正**无病历的空床**上，可以避开常规病历匹配与正常收治。

这不是隐形：鬼护士若肉眼看到明显违规、听到动静或在总查房时逐床检查，仍可能抓人；特殊病床上的空缺与未登记的人也不自动获得正式出院资格。

## 院方公示摘录

> 常规巡查：核当班病床档号，核已有登记。
>
> 无档空床：不入常规诊疗清单。
>
> 发现异人异床：记录异常，交班复核。
>
> 未获签发者：不得视作已出院。

# 第三封套｜双红交班

**创意核心**：鬼院长的全院恐怖，从一张有迹可循的**异常红单**开始。

【编剧设定提议】每个交班周期，护理站对照三种**实体记录**：

1. **床头病历卡**：这张床应对应哪份旧档。
2. **占床/转运登记簿**：现在实际把谁放在哪张床。
3. **诊疗流程单**：医师实际复核、处理、交接到了哪一步。

鬼护士发现矛盾时，必须现场确认并填写**“红色未结异常单”**。普通小错误或未实地核实的猜测不能登记为重大异常。

| 异常级别 | 可见条件 | 院方反应 |
|---|---|---|
| 单红 | 本交班周期，某一个床号出现**一项已核实、未销号的重大身份/去向不符** | 该病区局部追加巡查、暂缓相关转运 |
| 双红 | **两个不同床号**各有一张上述重大未结红单，且在**同一交班周期**仍无法核销 | 护理站提交异常簿；鬼院长实地或据真实医护记录完成复核后**启动总查房** |
| 已核销 | 对应人员、档案和床位的事实矛盾已用真实现场查清并更正 | 红单打销号章，不再累计；不是主角私自撕掉纸就能无后果撤销 |

**为什么要两个不同床号**：避免一处错误被同一人拆成两张单便随意发动“全院事件”。这是一种病态的行政门槛，不是岛屿系统的物理法则；怪物的“超我”驱动使它们强迫自己按程序行动。

**非魔法说明**：红单不会自行出现；需要实际发现、填写、送达。符合双红后，鬼院长仍需得到可信实物并做复核，才能响起胸腔“总查房”共鸣；不能在门后神奇看见所有床。主角可以争取时间、拖延或查证，但故意制造双红将让所有人面临更大的危险。

## 护理站交班簿（样张·剧情示例）

| 编号 | 床号 | 发现内容 | 实际核验 | 是否已销号 |
|---|---|---|---|---|
| R-01 | 017 | 临时占床号 C-07，与旧病历所载患者身份未复核 | 已见占床腕带与旧档不一致 | 未销号 |
| R-02 | 009 | 当班登记显示有人，但床上无人 | 鬼护士亲眼见到空床、查过最近转运栏仍无记录 | 未销号 |

**护理站交班结果：**“双红。暂停普通排班，提交鬼院长复核。”

此处没有“鬼院长凭空知道C-07在哪里”。它只会接到不符记录、要求医护重新查床、查人、查病历，并在确认异常后通过**胸腔共鸣器官**发出局部可听/可传播的总查房信号。

声音可提前被人物听见。医护队列改变、推床停在原地、楼梯出现成队脚步声，然后才是全院级危机。集结与搜查都需要真实时间和路线，人员并非瞬移。

# 第四封套｜鬼院长的执法边界

**鬼院长保留 v0.5 三项独有能力：**
- **总查房**：在满足双红等可观察的重大秩序混乱门槛后，组织真实医护分区核床、查人、查手续。
- **医疗问责**：鬼院长亲自或经可验证的实物记录查明鬼护士/医生违规；可把违规医护反过来强制收治。不是主角喊一句话就自动处罚。
- **强制清场**：III特殊个体借骨质前肢、夹钳和体格清除真正阻路的实体障碍；有身体、距离和战斗代价，不具病理矫正能力。

**正式出院唯一途径**仍是全部诊疗完成＋无待处理异常＋鬼院长复核签字。暂时从治疗室挣脱、问责医生、躲进无档空床，都不能作为豁免替代正式出院。

**医生专属能力**仍是病历对照、病理矫正、追加诊断与近身无菌切割。鬼护士执行抓捕登记，医生执行身体治疗，鬼院长执行行政秩序，谁都不是彼此的升级皮肤。

# 第五封套｜这一套机制怎么成为剧情

1. **入口规则与周启B1初遇先行（v0.7作者修订）**。三人进入疗养院时已经看见入口院规，但还不懂其实际危险；后因疑似查房脚步躲进B1储物间，陈七直接触醒早年因好奇A级天赋误入死眠的周启，**周启瞬间制服陈七**。周启本人不知道病历规则。周启**没有被谁移动到3F**；真正要推理的是“为什么这些旧院规仍有东西执行”“病历为什么属于床”。
2. **第三夜见“鬼护士”**。按旧工作稿，清醒的陈七也差点被推床抓捕，主角由此知道“他们不仅收昏迷的人”。第三夜**不应立刻出现鬼院长亲自执刀的情节**。
3. **后续见“医生”**。第017床的旧病历记载异常，陈七被临时错配；医师认为诊断正确、真人身体错误，开始准备治疗。角色第一次理解“病历随床”。
4. **“医生也会被收治”**。护理站已有017与009两床的红单，鬼院长总查房正在实地进行；小满发现医师未核实占床者身份便准备治疗，拿实际登记簿与术前签栏作证。鬼院长查实后问责医师，团队抓住因医护间争执产生的**短暂现实窗口**救出陈七。**这不是正式出院**，017的记录可能仍处于未解决状态。
5. **总查房的反向危机**。某次小满想用空床躲避查房，却发现护理站“未结异常：1”；他们必须选择冒险解决这张错账，还是撤走。如果队友又在另一床制造登记矛盾，将可能触发第二张红单。前一集让观众看到**红单由1变2**，下一集胸腔共鸣响起，视听爽点有公平铺垫。

# 第六封套｜尚未得到作者确认的三条选择

- **原始病历的真实年代与来源**：本提案只用“旧疗养院真实病历档案”的表层解释；是否和更大系统真相相关暂不揭晓。
- **双红交班阈值**：推荐同周期两个不同床号的重大身份/去向矛盾、经实地确认并未销号，鬼院长复核后才发动总查房。若创作者希望更不机械，可在后续改成“跨病区双红＋鬼院长裁量”，但必须同步改前期伏笔。
- **鬼院长总查房是否自动牵动医生**：建议只是调度医护行动和核对流程，不会让每位医生瞬间得到全部病历信息或暂停手术。问责仍需实地可核实。
