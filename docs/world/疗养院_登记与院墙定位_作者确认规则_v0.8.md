# 疗养院｜永久登记、全院感应与院墙边界 v0.8

> 状态：**【作者于2026-11-03对话中明确确认】**。优先于旧v0.5/v0.6的冲突性工作提案；具体病历源头、红单与医生问责流程仍未定稿。

## 一、明确确认的规则

1. **登记不可逆**。一个人一旦被正式写进疗养院登记簿，患者身份永久保留。撕毁腕带或纸页、逃出院墙、熬到下一批船抵达都不等于注销登记。
2. **全院医护实时感应**。登记者只要处于院墙以内，所有医护均可直接感知其准确位置，不需要先查登记簿、传话、看到人或发现足迹。
3. **院墙为生效边界**。院墙内的主楼、地下室、院子、花园等都算院区。已登记者跨出院墙后，这项精确定位立即失效；将来再次踏入院墙以内，无需再登记便立即重新激活定位与强制收治。
4. **只有值班者负责抓人**。值班者抓捕、控制、押送、收治登记。执刀医师负责接诊、诊疗与病历矫正，**不主动抓人**。院长负责维护收治秩序，在持续严重收治受阻或值班者／医生死亡过多时介入，**不代替值班者执行日常抓捕**。全员感应不等于全员围攻。
5. **感应不等于瞬移**。值班者虽然知道位置，仍要沿真实走廊、楼梯、门和室外路径赶到；门闩、物理遮挡和时间差可以争取撤离窗口，但不能消除被定位的事实。
6. **下一批船结束的是当期强制诊疗义务**，不是永久登记。即使撑到下一批船来，本人以后再次踏入疗养院，也会重新激活强制收治。

## 二、状态速查

| 状态 | 全院感应 | 抓捕判定 |
| --- | --- | --- |
| 未登记，在院墙内 | 不受登记定位能力影响，仍可能被巡视发现 | 值班者发现后可以抓捕登记 |
| 已登记，躲病房、地下室或院内花园 | 所有医护知道准确位置 | 值班者沿实路追捕，藏身无效 |
| 已登记，冲出院墙 | 院内感应失效 | 该登记规则不再提供院外追捕定位；院外其他危险独立存在 |
| 已登记，撑到下一批船抵达 | 登记依旧留存 | 当前轮次诊疗义务结束；未来重入院墙即恢复收治 |
| 已登记，下一轮再进院墙 | 即时恢复全院感应 | 无需重新登记，值班者继续执行收治 |

**注意**：院外普通目视、听觉或其他怪物行为不等于院内登记定位。院墙的成因以及院外怪物为何止步，仍为独立悬念。

## 三、明确不能混为正史的候选

- v0.5：值班者／执刀医师／院长的具体阶位、技能、强制清场的细目尚属工作方案；只锁定“值班者才抓人，医生不会”的作者边界。
- v0.6：**病历随床**、双红交班、17号床旧病史、旧病历来源、院长总查房触发门槛仍为工作提案。登记定位不依赖红单触发。
- 旧版“全部诊疗完成＋无异常＋院长签字”可以继续讨论为院内正式出院流程，但**不得据此推断永久登记可注销**。正式出院是否能提前结束当期义务仍待明确。
- 未登记者藏在无病历空床可规避常规查房的细则仍是候选；**已登记者无法靠空床躲过全院感应**。

## 四、故事连接与人物知情

[《第十七床》EP01—EP07工作稿](../story/疗养院第三夜_第十七床_EP01-EP07_剧本工作稿_v0.8.md)采用这套机制：陈七为救小满被登记者收治，周启只救得出人，不能抹消永久登记；四人冲出院墙暂脱追踪。

观众可先看到全院医护抬头感应的事实；角色只能通过被准确追踪的可见现象逐步推断。周启当年因好奇A级天赋在B1自发死眠、不曾被搬到三楼、也不懂现行病历机制，不能当规则解说员。

仍待定：院区边界形成原因、感应的外观表现、正式登记动作的详细有效条件、提前结束当期义务的方式、院长具体技能与出场过程（两条介入原因已在v1.0确认）。
