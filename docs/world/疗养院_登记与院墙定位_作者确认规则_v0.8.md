# 疗养院｜永久登记、全院感应与院墙边界 v0.8

> 状态：**【作者于2026-11-03对话中明确确认】**。优先于旧v0.5/v0.6的冲突性工作提案；具体病历源头、红单与医生问责流程仍未定稿。

## 一、明确确认的规则

1. **登记不可逆**。一个人一旦被正式写进疗养院登记簿，患者身份永久保留。撕毁腕带或纸页、逃出院墙、熬到下一批船抵达都不等于注销登记。
2. **全院医护实时感应**。登记者只要处于院墙以内，所有医护均可直接感知其准确位置，不需要先查登记簿、传话、看到人或发现足迹。
3. **院墙为生效边界（Day13及更早已证实的常态规则）**。院墙内的主楼、地下室、院子、花园等都算院区。已登记者跨出院墙后，常态下这项精确定位失效；再次踏入院墙以内，无需再登记便重新激活定位与强制收治。**但Day14永夜升阶后鬼院长与鬼医生在院外仍似能追索二人，说明常态边界可能异常扩大；新机制尚未解明。**
4. **只有鬼护士负责抓人**。鬼护士抓捕、控制、押送、收治登记。鬼医生负责接诊、诊疗与病历矫正，**不主动抓人**。鬼院长负责维护收治秩序，在持续严重收治受阻或鬼护士／医生死亡过多时介入，**不代替鬼护士执行日常抓捕**。全员感应不等于全员围攻。
5. **感应不等于瞬移**。鬼护士虽然知道位置，仍要沿真实走廊、楼梯、门和室外路径赶到；门闩、物理遮挡和时间差可以争取撤离窗口，但不能消除被定位的事实。
6. **下一批船结束的是当期强制诊疗义务**，不是永久登记。即使撑到下一批船来，本人以后再次踏入疗养院，也会重新激活强制收治。

## 二、状态速查

| 状态 | 全院感应 | 抓捕判定 |
| --- | --- | --- |
| 未登记，在院墙内 | 不受登记定位能力影响，仍可能被巡视发现 | 鬼护士发现后可以抓捕登记 |
| 已登记，躲病房、地下室或院内花园 | 所有医护知道准确位置 | 鬼护士沿实路追捕，藏身无效 |
| 已登记，冲出院墙 | 院内感应失效 | 该登记规则不再提供院外追捕定位；院外其他危险独立存在 |
| 已登记，撑到下一批船抵达 | 登记依旧留存 | 当前轮次诊疗义务结束；未来重入院墙即恢复收治 |
| 已登记，下一轮再进院墙 | 即时恢复全院感应 | 无需重新登记，鬼护士继续执行收治 |

**注意**：院外普通目视、听觉或其他怪物行为不等于院内登记定位。院墙的成因以及院外怪物为何止步，仍为独立悬念。

## 三、明确不能混为正史的候选

- v0.5：鬼护士／鬼医生／鬼院长的具体阶位、技能、强制清场的细目尚属工作方案；只锁定“鬼护士才抓人，医生不会”的作者边界。
- v0.6：**病历随床**、双红交班、17号床旧病史、旧病历来源、鬼院长总查房触发门槛仍为工作提案。登记定位不依赖红单触发。
- 旧版“全部诊疗完成＋无异常＋鬼院长签字”可以继续讨论为院内正式出院流程，但**不得据此推断永久登记可注销**。正式出院是否能提前结束当期义务仍待明确。
- 未登记者藏在无病历空床可规避常规查房的细则仍是候选；**已登记者无法靠空床躲过全院感应**。
