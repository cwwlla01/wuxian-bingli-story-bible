# 05｜天赋技能、刑纹与战力边界

> 刑纹存在期间持续疼痛并增强战力。S「处刑者」核心链条为「定罪→罪己形成刑纹→刑纹持续生效→处刑消耗刑纹」。

| 角色 | 天赋 | 稳定效果与硬性边界 |
| --- | --- | --- |

| 苏小满 | **B·灵丝** | 有真实锚点、承力、数量、持续时间限制；可报警、短绊阻、协作，不能凭空吊成年人或轻松切开四五阶怪物 |
| 周启 | **A·不死战躯** | 肉体战斗、修复与死眠能力；死眠必须由**活人直接触肤**唤醒，期间不能自主防卫；长眠有代价，不能即刻修复所有伤或单挑完整五阶 |
| 阿禾 | **S·处刑者** | 独立人格专属主动技能；不能当林渊共情升级，不能无代价越阶秒杀 |

| 韩震 | **A·铁骨** | 主动强化骨骼承力，尤其适合以前臂、肩背格挡或顶住冲击；冲力仍会传到肌肉、关节和内脏，仍会后退、疼痛或受伤，不是全身无敌护甲。持续硬抗会使体力和承伤部位累积损耗 |
| 罗峰 | **A·影跃** | 可在同一连续空间内向本人直接看见、确认落点的近处位置完成一次短距跃移；可带本人手持的轻物，不带人、不穿不透明墙体、不跳往未知或未确认地点。落点必须真实可站，连续使用会明显消耗体力并扰乱平衡 |

| 孙浩 | **B·火种** | 能在视线内的短距离点燃少量干燥、易燃材料，形成一处小火源；必须有真实燃料，火焰大小和持续时间由燃料与环境决定。不能凭空造燃料、发射火球或遥控扩展现有火势；潮湿、缺氧和外力都能使火熄灭 |

| 魏叔 | **C·固障** | 触碰一处真实存在的门、隔板或类似结构时，可短时稳住其当前连接与受力状态，争取数秒处理时间；必须依托现有实体，不能凭空造盾或把普通材料变成不可破坏。持续期间需维持接触并承受疲劳，无法长期顶住高阶怪物的连续冲击 |
| 刘斌 | **C·引惑** | 可短时提高一个目标对现实中已存在、且目标能够感知的声音或动作的注意度；不能制造刺激、控制思想、强迫目标移动或打断已发动的攻击。目标听不见/看不见时无效；用真实物件敲击制造噪声仍是普通动作，不自动算作天赋发动 |
| 蒋文 | **C·异鉴** | 近距离观察或触检一个具体对象时，可察觉一项明显异常的材质、结构或状态差异；判断需要可见依据或对照，不会自动说明原因、用途和完整历史。不能隔墙读取、扫描整片区域、识别怪物弱点或替代系统的名称与等阶提示 |

没有在现行分场中明确发动的天赋，不回填成既有动作的隐形原因；首次正面使用时按本表呈现。凡效果需要真实声音、燃料、落点、承力结构或身体接触，现场必须具备对应条件。

## 天赋的心源映射

挑战系统会把每个人长期、稳定的核心执念、愿望或心理缺口显化为天赋方向。人物不自选技能，天赋也不会按字面替人完成愿望；心源决定能力的精神意象与人物冲突，不自动决定品阶、数值、战斗胜负，也不取消技能的触发条件、范围、代价和失败边界。角色本人未必知道心源与天赋的关系，第一季不提前揭示系统如何读取或转译这些心理经验。

## 系统识别与天赋的分工

参与者**不需要发动天赋**，只要本人在可见条件下清楚辨出怪物，即可短暂读到**【名称·当前怪物等阶】**。这属于**人人可用的系统基础识别**，不是林渊C「共情」、蒋文C「异鉴」或阿禾S「定罪」的主动升级；不提供弱点、血条、怪物技能档案或保底掉落。**只有阿禾主动使用S「定罪」**，才可能识别具体目标致命软处，但知弱点仍不等于安全破甲或自动命中。界面和渐进图鉴详[09](09_怪物识别_渐进图鉴_现行机制.md)。

## S「处刑者」现行机制

1. **定罪**：识别目标具体致命弱点。知道弱点**不等于**自动命中或破甲。
2. **罪己**：对自己施加处刑，身体上生成刑纹；过程有真实身体/精神代价。
3. **刑纹**：**只要存在，就持续产生疼痛，同时持续增强战斗力。** 睡眠、昏迷、换人格不等于自动失效；强化不能抹去真实疼痛与身体损耗。
4. **处刑**：主动**消耗积累的刑纹**发动高强度打击，消耗越多威力与反噬越高。**消耗后的余纹数量、痛感及增幅如何变化、如何恢复，均尚未锁定**，不得臆造“归零即无痛”或固定回复分钟。

**战斗连续性：** Day3首次「罪己」与Day13再次「罪己」的现行编剧方案都生成刑纹；只要纹仍在，**疼痛和战斗增幅同时持续**。Day13牵制院长后短暂昏迷，Day14有限恢复后依靠仍存的刑纹、地形、团队与医生手术刀击杀双四阶鬼医生，**不在Day14额外发动「罪己」「处刑」**。Day15「定罪」识别五阶院长**眉心**，但既有手术刀及普通声狩刀臂都无法常态穿透完整额骨甲；【优化提案】小满偏开诊尺、陈七短拖护士→阿禾大量消耗**原已存在**的刑纹发动「处刑」破额甲→周启持Day14**第一把鬼医生手术刀**从**同一破口**补上致命一击→阿禾共身严重反噬、昏迷近三天，林渊不即时接管。**消耗后的余纹数量及疼痛/增幅变化仍未锁定**，不能凭推测宣布无痛清零。

## 战力与系统级别

- 玩家天赋常用F—S表示稀有性与潜力，怪物I—V是威胁等级；**二者不是同一数轴**。战力受伤势、地形、装备、经验与协作影响。
- 陈七、小满可以通过训练与合作逐渐战胜较低阶个体，但不能因此宣称可稳定单挑四阶。
- 武器与怪物材料必须靠真实获取、运送、加工；晶体**不是每只怪物必掉**，用途尚未揭晓。世界规则也不提供无条件瞬移或一夜治愈。
