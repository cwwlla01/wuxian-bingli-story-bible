## 系统识别与天赋的分工

参与者**不需要发动天赋**，只要本人在可见条件下清楚辨出怪物，即可短暂读到**【名称·当前怪物等阶】**。这属于**人人可用的系统基础识别**，不是林渊C「共情」、蒋文C「异鉴」或阿禾S「定罪」的主动升级；不提供弱点、血条、怪物技能档案或保底掉落。**只有阿禾主动使用S「定罪」**，才可能识别具体目标致命软处，但知弱点仍不等于安全破甲或自动命中。界面和渐进图鉴详[09](09_怪物识别_渐进图鉴_现行机制_v1.0.md)。

## S「处刑者」现行机制

1. **定罪**：识别目标具体致命弱点。知道弱点**不等于**自动命中或破甲。
2. **罪己**：对自己施加处刑，身体上生成刑纹；过程有真实身体/精神代价。
3. **刑纹**：**只要存在，就持续产生疼痛，同时持续增强战斗力。** 睡眠、昏迷、换人格不等于自动失效；强化不能抹去真实疼痛与身体损耗。
4. **处刑**：主动**消耗积累的刑纹**发动高强度打击，消耗越多威力与反噬越高。**消耗后的余纹数量、痛感及增幅如何变化、如何恢复，均尚未锁定**，不得臆造“归零即无痛”或固定回复分钟。

**战斗连续性：** Day3首次「罪己」与Day13再次「罪己」的现行编剧方案都生成刑纹；只要纹仍在，**疼痛和战斗增幅同时持续**。Day13牵制院长后短暂昏迷，Day14有限恢复后依靠仍存的刑纹、地形、团队与医生手术刀击杀双四阶鬼医生，**不在Day14额外发动「罪己」「处刑」**。Day15「定罪」识别五阶院长**眉心**，但既有手术刀及普通夜巡者刀臂都无法常态穿透完整额骨甲；【优化提案】小满偏开诊尺、陈七短拖护士→阿禾大量消耗**原已存在**的刑纹发动「处刑」破额甲→周启持Day14**第一把鬼医生手术刀**从**同一破口**补上致命一击→阿禾共身严重反噬、昏迷近三天，林渊不即时接管。**消耗后的余纹数量及疼痛/增幅变化仍未锁定**，不能凭推测宣布无痛清零。

## 战力与系统级别

- 玩家天赋常用F—S表示稀有性与潜力，怪物I—V是威胁等级；**二者不是同一数轴**。战力受伤势、地形、装备、经验与协作影响。
- 陈七、小满可以通过训练与合作逐渐战胜较低阶个体，但不能因此宣称可稳定单挑四阶。
- 武器与怪物材料必须靠真实获取、运送、加工；晶体**不是每只怪物必掉**，用途尚未揭晓。世界规则也不提供无条件瞬移或一夜治愈。
