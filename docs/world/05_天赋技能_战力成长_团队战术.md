# 05｜天赋技能、刑纹与战力边界

> **作者最新明确：刑纹持续疼痛，同时持续增强战力。** 现行S「处刑者」核心链条是「定罪→罪己形成刑纹→刑纹持续生效→处刑消耗刑纹」。**旧「行刑」「忏悔」「自然退纹」不是当前已锁机制**，不得写回新分集。

## S「处刑者」现行机制

1. **定罪**：识别目标具体致命弱点。知道弱点**不等于**自动命中或破甲。
2. **罪己**：对自己施加处刑，身体上生成刑纹；过程有真实身体/精神代价。
3. **刑纹**：**只要存在，就持续产生疼痛，同时持续增强战斗力。** 睡眠、昏迷、换人格不等于自动失效；强化不能抹去真实疼痛与身体损耗。
4. **处刑**：主动**消耗积累的刑纹**发动高强度打击，消耗越多威力与反噬越高。**消耗后的余纹数量、痛感及增幅如何变化、如何恢复，均尚未锁定**，不得臆造“归零即无痛”或固定回复分钟。

**战斗连续性：** Day13「罪己」增刑纹，阿禾痛与战力同时上升，牵制四阶院长后昏迷；Day14苏醒（具体时点为编剧接桥方案）时若刑纹尚在，仍痛且有增幅，凭弱点、团队与手术刀击杀双四阶鬼医生；Day15对五阶院长厚骨甲依旧无法常态破防，需以「处刑」大量消耗刑纹打穿骨甲，周启补刀，阿禾因此再昏迷近三天。

## 战力与系统级别

- 玩家天赋常用F—S表示稀有性与潜力，怪物I—V是威胁等级；**二者不是同一数轴**。战力受伤势、地形、装备、经验与协作影响。
- 陈七、小满可以通过训练与合作逐渐战胜较低阶个体，但不能因此宣称可稳定单挑四阶。
- 武器与怪物材料必须靠真实获取、运送、加工；晶体**不是每只怪物必掉**，用途尚未揭晓。世界规则也不提供无条件瞬移或一夜治愈。
