# 08｜正式怪物名称与区域对应

> **作者2026-11-06已确认的命名入口。** 旧名、曾使用的七类分类和未锁定的后季怪物不再作为现行名称。机制详[03｜怪物与疗养院机制](03_怪物与疗养院机制_现行规则.md)；剧情见[第一季五阶段大纲](../大纲/README.md)。

**正式名称的系统可见性：** 名称表提供真实世界物种名称，并非角色开局已获得的完整怪物百科。参与者只要**本人直接看见怪物本体的任一部分**（包括局部或远处轮廓），意识中就会轻响一声仅本人感知的**「叮」**，随后短暂显示该个体**【名称·当前等阶】**；无需看清全身或先认出物种，完全遮挡或仅听见声音时不触发。同一只怪物重复入镜不重响，升阶后重新看见才再次提示并更新标签。其他名称、分布、具体习性、弱点均不能从本表自动同步到角色。**铁颚为任务专名，须单独确认**。具体见[09｜识别与渐进图鉴](09_怪物识别_渐进图鉴_现行机制_v1.0.md)。

## 二、当前已确认的相关世界线

1. **日照与全岛升阶。** Day3 06:00日出、17:00落山，此后日照逐日缩短；Day14 06:00无日出、真正永夜，各类怪物**整体提升一阶**且跨原活动范围骚动。参与者只有重新直接看见具体个体，才会获知其更新后的阶位。旧图鉴将I—V写成固定等级上限的表述只能当此前观测范围，**不得用来否定更高阶怪的可能**。
2. **鬼院长进阶与死亡。** Day6后医护死伤、收治工作多次受阻，院长室黑雾已积累；Day13鬼医生于12:00上报多处病床被移走，成为**A类持续严重受阻**的重大触发，四阶鬼院长才凝形。**不是一张床少了就必定召唤，也未定B类医护死亡阈值。** Day14院长升五阶、实路越界杀死同样升五阶的魔熊而重伤；Day15阿禾「定罪」找眉心、「处刑」消耗原有刑纹破骨甲，周启用Day14第一把医生手术刀从同一破口致命。
3. **两名鬼医生与战利品。** Day14两名原三阶鬼医生升为四阶，**沿实体林道异常越出院区**；实际看见陈七、小满后，分别逼近执行危险的**近身诊疗**，不承担鬼护士的主动抓捕/登记职责。医生为何越界以及永夜后是否有异常指向机制**仍未揭晓**，不能据此宣布平时可院外精确锁定患者。第一只在旧卸木场滚木短压后，经阿禾「定罪」找颈侧软处、周启阿禾反复实击才死；周启从尸体取第一把刀，第二只逼近陈七，周启用新刀破颈甲、阿禾补击杀死。**共两具四阶医生尸体、两把手术刀、两颗黑晶**，不是滚木或单次刺击自动秒杀。
4. **魔熊、声狩资源。** 五阶魔熊被鬼院长杀死，留下**一颗五阶魔晶**和整张沉重熊皮；周启与阿禾合力抬回，利用林场工具做四套简易护甲。五阶交战地点另有**七八具四阶声狩遗体**，其中只有部分有晶体；周启仅取一套刀盾，普通铁具不如它、鬼医生手术刀又优于它。怪物尸体**并非必定出晶体**。
5. **永夜收束。** Day16怪物躁动逐渐停止、逐步归区；Day17大多返回原活动带，仍不能认定已降阶；**Day18白昼重现，下一批游轮靠岸**，不据此自动断言系统积分、晶体、登记身份或怪物等级被重置。
6. **登记与追踪。** Day13完成正式病人登记的是**陈七、小满两人**，在疗养院二楼相邻房间；此前院区范围内感应与永久登记规则仍是基础。Day14永夜后两人在外界感到被鬼院长/鬼医生追索的相似注视，**范围似已异常扩大**，机制因果仍待后续揭晓。鬼院长死亡不自动证明病人身份被注销。
7. **既有分类与禁混。** 鬼护士在院内负责走廊巡查抓捕、正式登记；鬼医生在病房巡检、异常上报及已登记病人处置；鬼院长对重大异常行动，**不替代二者全部日常职责**。声狩为岛上夜行怪物，不能写成同一批鬼护士。不同区域列出同名魔熊不代表人为增加个体数量。
