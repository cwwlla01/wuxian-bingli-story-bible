**名称消歧：** 旧稿有不止一种字形指称普通鳄形敌人，一律改为**「巨鳄」**，不保留为两个新的不同族群。旧名只在Git历史或旧文件路径中出现，**以后叙事文本和图鉴不要沿用**。

## 二、当前已确认的相关世界线

1. **日照与全岛升阶。** Day3 06:00日出、17:00落山，此后日照逐日缩短；Day14 06:00无日出、真正永夜，各类怪物**整体提升一阶**且跨原活动范围骚动。旧图鉴将I—V写成固定等级上限的表述只能当此前观测范围，**不得用来否定更高阶怪的可能**。
2. **鬼院长进阶与死亡。** Day13因医院已积累的怪物伤亡导致院长室黑雾蓄势，鬼医生发现大量病床缺失并上报严重异常，黑雾凝为**四阶鬼院长**；Day14鬼院长升**五阶**、可以离院，和同样升五阶的魔熊搏杀，杀死魔熊但严重受伤；Day15在三楼院长室被四人反攻击杀——阿禾「定罪」锁定额心弱点，「处刑」消耗刑纹破面骨甲，周启手术刀最终刺杀。旧稿的“特殊III阶/本季不死”不可沿用。
3. **两名鬼医生与战利品。** Day14两名曾为三阶的鬼医生升为四阶、越过疗养院寻找已登记的陈七、小满。周启先利用旧卸木场滚木、阿禾「定罪」弱点脖子并重复斩击杀第一只；缴获锋利手术刀，经尸体试刃后四人合力从背后刺穿第二只颈部。共**两名四阶鬼医生被杀、两把手术刀（周启与阿禾各一）、两颗四阶黑晶**。
4. **魔熊、夜巡者资源。** 五阶魔熊被鬼院长杀死，留下**一颗五阶魔晶**和整张沉重熊皮；周启与阿禾合力抬回，利用林场工具做四套简易护甲。五阶交战地点另有**七八具四阶夜巡者遗体**，其中只有部分有晶体；周启仅取一套刀盾，普通铁具不如它、鬼医生手术刀又优于它。怪物尸体**并非必定出晶体**。
5. **永夜收束。** Day16怪物躁动逐渐停止、逐步归区；Day17大多返回原活动带，仍不能认定已降阶；**Day18白昼重现，下一批游轮靠岸**，不据此自动断言系统积分、晶体、登记身份或怪物等级被重置。
6. **登记与追踪。** Day13完成正式病人登记的是**陈七、小满两人**，在疗养院二楼相邻房间；此前院区范围内感应与永久登记规则仍是基础。Day14永夜后两人在外界感到被鬼院长/鬼医生追索的相似注视，**范围似已异常扩大**，机制因果仍待后续揭晓。鬼院长死亡不自动证明病人身份被注销。
7. **既有分类与禁混。** 鬼护士在院内负责走廊巡查抓捕、正式登记；鬼医生在病房巡检、异常上报及已登记病人处置；鬼院长对重大异常行动，**不替代二者全部日常职责**。夜巡者为岛上夜行怪物，不能写成同一批鬼护士。不同区域列出同名魔熊不代表人为增加个体数量。
