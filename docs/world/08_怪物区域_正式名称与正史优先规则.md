# 08｜正式怪物名称与区域对应

> 本表统一第一季现行怪物名称与区域关系。机制详[03｜怪物与疗养院机制](03_怪物与疗养院机制_现行规则.md)；剧情见[第一季五阶段大纲](../大纲/README.md)。

**正式名称的系统可见性：** 名称表提供真实世界物种名称，并非角色开局已获得的完整怪物百科。参与者只要**本人直接看见怪物本体的任一部分**（包括局部或远处轮廓），意识中就会轻响一声仅本人感知的**「叮」**，随后短暂显示该个体**【名称·当前等阶】**；无需看清全身或先认出物种，完全遮挡或仅听见声音时不触发。同一只怪物重复入镜不重响，升阶后重新看见才再次提示并更新标签。其他名称、分布、具体习性、弱点均不能从本表自动同步到角色。**铁颚为任务专名，须单独确认**。具体见[09｜识别与渐进图鉴](09_怪物识别_渐进图鉴_现行机制.md)。

## 各物种活动范围与永夜移动规则

下表是创作者侧的区域连续性设定，不是挑战者开局获得的怪物地图。除声狩外，各物种有相对稳定的主要活动范围；个体可以沿相连道路短距离追击或觅食，但不因普通夜晚或叙事需要而任意跨区出现。Day14永夜初临后的短时躁动是例外：怪物整体升阶并发生有限跨区移动；Day16—17逐渐返回原活动带。此后在持续永夜中，**声狩是唯一常态跨区域夜行的怪物**，其他物种仍以各自活动范围为界。具体个体的既定追击路线优先于一般分布表，不由此新增怪物数量。

| 正式名称 | 主要活动范围 | 移动边界与本季用途 |
| --- | --- | --- |
| **巨鳄** | 断轨沟、旧铁路货运道、仓库及港镇外围的相连街区；西、北区主街可有分散群体 | 主要沿岛北货运走廊和相连街区移动。Day3三只普通III从断轨沟分流、Day4一只回到仓库东侧，是同一个体的连续行程，不代表全岛游荡。 |
| **骨犬** | 北部港口旧上坡路、港镇外围街巷、南部农林区边缘 | 以边缘道路和林缘为活动带；可有落单个体出现在东区旧供给巷或镇南商铺附近，不形成跨越全镇的成群迁徙。 |
| **缝声人** | 港镇西、北区居民街巷、边缘屋舍，以及南向旧路沿线的废弃住屋 | 活动围绕有人居住过的街区和旧屋；声音可以从屋外传入，但只有实体进入视线才触发识别。不会常态跨越岛屿游荡。 |
| **鱼人** | 港镇南区旧供水路、排水沟及与之相连的潮湿地下通道 | 只把这条水道系统作为活动范围，不扩展到灰黑海域或全岛河流。第一季Day4三人未遇见鱼人；等阶、能力、习性与具体个体数不预设。 |
| **鬼护士** | 疗养院围墙内的病区、走廊、公共区与后勤通路 | 在院内依职责巡查、抓捕、押送和登记；不常态巡游城镇。永夜院外追索是医院规则异常，不等于鬼护士拥有全岛活动范围。 |
| **鬼医生** | 疗养院围墙内的病房、诊疗区与相关走廊 | 日常活动限于院内诊疗与病历职责。Day14越界接近登记者是本季已发生的异常事件，不改变其常态范围。 |
| **鬼院长** | 疗养院及院长室 | 因重大收治异常在院内介入。Day14离院与魔熊交战属于单次剧情事件，不设为日常跨区巡游。 |
| **魔熊** | 南部农林区、旧林业站、旧卸木场及周围林地 | 熊群活动集中在连续林地与林业设施附近，不进入港镇或北部岛区。 |
| **巢母** | 东部工业供水带的泵站及相连设施 | 属于固定工业区域威胁；本季未安排出场，不向港镇或疗养院扩散。 |
| **渊骸巨兽** | 东南矿区裂谷、矿道和施工营地 | 属于矿区深处的固定威胁；本季未安排出场，不设为地表游荡个体。 |
| **声狩** | 无固定巢穴；沿全岛可通行的夜路、林缘和建筑外缘巡游 | 唯一常态跨区域夜行者。永夜躁动期活动更频繁；巡游仍受实体地形限制，不瞬移，也不等同于疗养院医护。 |

**新增判断：** 不再增设新物种。鱼人已经作为既有名称保留，给它明确的南区旧水道生态位即可；它可留作后续水道篇的未知威胁，但不必为了“补怪”强行插入当前分集梗概，也不预先锁定其战斗能力。

**特殊个体：** 首批任务指定三阶BOSS的专名**「铁颚」**保留，它是系统指定目标，不等同于又新增一种独立普通物种。其与普通巨鳄在生物学上的细节关系没有得到新增确认。

**名称规范：** 普通鳄形敌人统一称为**「巨鳄」**，同一物种不因称呼差异拆分为多个族群。

## 二、当前已确认的相关世界线

1. **日照与全岛升阶。** Day3 06:00日出、17:00落山，此后日照逐日缩短；Day14 06:00无日出、真正永夜，各类怪物**整体提升一阶**且跨原活动范围骚动。参与者只有重新直接看见具体个体，才会获知其更新后的阶位。旧图鉴将I—V写成固定等级上限的表述只能当此前观测范围，**不得用来否定更高阶怪的可能**。
2. **鬼院长进阶与死亡。** Day6后医护死伤、收治工作多次受阻，院长室黑雾已积累；Day13鬼医生于12:00上报多处病床被移走，成为**A类持续严重受阻**的重大触发，四阶鬼院长才凝形。**不是一张床少了就必定召唤，也未定B类医护死亡阈值。** Day14院长升五阶、实路越界杀死同样升五阶的魔熊而重伤；Day15阿禾「定罪」找眉心、「处刑」消耗原有刑纹破骨甲，周启用Day14第一把医生手术刀从同一破口致命。
3. **两名鬼医生与战利品。** Day14两名原三阶鬼医生升为四阶，**沿实体林道异常越出院区**；实际看见陈七、小满后，分别逼近执行危险的**近身诊疗**，不承担鬼护士的主动抓捕/登记职责。医生为何越界以及永夜后是否有异常指向机制**仍未揭晓**，不能据此宣布平时可院外精确锁定患者。第一只在旧卸木场滚木短压后，经阿禾「定罪」找颈侧软处、周启阿禾反复实击才死；周启从尸体取第一把刀，第二只逼近陈七，周启用新刀破颈甲、阿禾补击杀死。**共两具四阶医生尸体、两把手术刀、两颗黑晶**，不是滚木或单次刺击自动秒杀。
4. **魔熊、声狩资源。** 五阶魔熊被鬼院长杀死，留下**一颗五阶魔晶**和整张沉重熊皮；周启与阿禾合力抬回，利用林场工具做四套简易护甲。五阶交战地点另有**七八具四阶声狩遗体**，其中只有部分有晶体；周启仅取一套刀盾，普通铁具不如它、鬼医生手术刀又优于它。怪物尸体**并非必定出晶体**。
5. **永夜收束。** Day16怪物躁动逐渐停止、逐步归区；Day17大多返回原活动带，仍不能认定已降阶；**Day18白昼重现，下一批游轮靠岸**，不据此自动断言系统积分、晶体、登记身份或怪物等级被重置。
6. **登记与追踪。** Day13完成正式病人登记的是**陈七、小满两人**，在疗养院二楼相邻房间；此前院区范围内感应与永久登记规则仍是基础。Day14永夜后两人在外界感到被鬼院长/鬼医生追索的相似注视，**范围似已异常扩大**，机制因果仍待后续揭晓。鬼院长死亡不自动证明病人身份被注销。
7. **既有分类与禁混。** 鬼护士在院内负责走廊巡查抓捕、正式登记；鬼医生在病房巡检、异常上报及已登记病人处置；鬼院长对重大异常行动，**不替代二者全部日常职责**。声狩为岛上夜行怪物，不能写成同一批鬼护士。不同区域列出同名魔熊不代表人为增加个体数量。
