# 09｜怪物识别与渐进图鉴：现行机制 v1.0

> **作者2026-11-07新增并确认的系统规则。** 参与者只要直接看见怪物本体的任一部分，系统便以本人可见的短浮字提示**正式名称＋当前威胁等阶**；无需靠近、看清全身或先认出物种。详细图鉴不在开局赠送，而是随个人实际遭遇和调查逐步积累。本文件为识别与图鉴专门入口；怪物名称和已确认区域从[08｜正式怪物命名](08_怪物区域_正式名称与正史优先规则_v1.0.md)，医院登记从[03｜怪物与疗养院机制](03_怪物与疗养院机制_现行规则.md)，角色天赋从[05｜天赋技能](05_天赋技能_战力成长_团队战术.md)。

## 一、首次看到：自动显示名字与当前等阶

1. **触发条件：本人直接看见怪物本体。** 参与者只要在现场将视线落到怪物本体的任一可见部分，即使只是局部或远处轮廓，系统就自动识别并短暂显示正式物种名、当前等阶；不要求角色先判断物种、看清全身或靠近。怪物完全被墙体等遮挡、只听到声音或仅从他人口述得知时不触发。系统不透视墙体，也不扫描视线外目标；标签只对本人可见，其他亲眼看见的参与者也会各自获得标签。
2. **显示内容仅两项：正式物种名、当前等阶。** 标准例：**【骨犬·I阶】**、**【巨鳄·II阶】**、**【鬼护士·III阶】**、**【魔熊·IV阶】**。对同物种不同个体分别显示其当前等级，标签不说明数量、坐标、血量或死亡概率。失去清楚目视后目标上的浮字熄灭，但此前成功记录的名称可留在个人图鉴。
3. **名阶由系统识别，角色不必代猜。** 只要怪物本体的任一部分进入本人视野，系统就显示其真实物种名和当前等阶；局部甲背、肢体或远处轮廓同样触发。角色仍需自己数数量、确认路线与方位、分辨是否同一只；完全看不见的目标不会出现标签。视觉标签是有限的系统辅助，**不是天赋能力，也不代表角色自动会打。**
4. **人物天赋等第与怪物威胁阶位完全独立。** 玩家为F—S天赋资质；怪物为I、II、III、IV、V……当前威胁等级。**I—V不是系统永久上限**。Day14真正无日出时怪物整体升一阶；只有参与者之后再次直接看见该目标，标签才会更新成新阶位，不提前对所有人广播全岛实时名册。
5. **提示短促、克制。** 首次遭遇可出现一帧清晰标签；同种重复遭遇不必每镜头刷字；仅在误判等级、阶段升阶或观众理解风险需要时复现。浮字只有参与者感知，**不在怪物身上形成实体光标，也不提示其行踪**。

## 二、任务指名例外：铁颚不是普通扫描就能查出的身份

- 开局系统共同任务**已经公开指定「III阶·铁颚」**，这是**任务文本**而不是全图怪物识别；没有坐标、全岛追踪或任务目标透视。
- 只要直接看见巨鳄本体，该目标的**普通怪物浮字就会显示【巨鳄·当前等阶】**，包括仅见局部鳄甲或远处轮廓时。这个标签不会自动证明它就是铁颚；专名仍须现场事实与任务模块核对。
- **「铁颚」的个体任务身份**，须角色依实地特征、完整视角和现场任务目标核对作出确认后，**任务模块才显示【指定目标确认：铁颚·III阶】**。**身份确认不等于知道其肩甲弱点**；唐梨的能力、人物走位与实地观察仍必需。此项为任务身份核对，非扫描万物的专名数据库。
- 普通同族III阶巨鳄不会因为等级相同就被误标成任务BOSS；指定铁颚击杀成功后仍须原系统任务成功确认、触发既定离港倒计时。

## 三、渐进图鉴：记录遭遇，不发攻略

| 图鉴状态 | 解锁来源 | 可以留下的内容 | 系统不得免费提供 |
| --- | --- | --- | --- |
| **未遭遇** | 未在可见距离辨清目标 | 空白，或只保留任务明确公开的字面信息 | 全岛怪物名单、活动坐标、隐藏BOSS |
| **已识别** | 第一次亲眼看清 | 正式名称、当时目视的等阶、首次记录时间（若系统已有时钟） | 弱点、技能清单、巢穴地图、掉落表 |
| **观察记录** | 参与者亲眼看见攻击、移速、觅食或活动带 | **仅记录其本人看过的事实**：如“刃臂拖石”“沿实巷追声”“在卸木棚附近觅食” | 未试过的反制方法、怪物未来意图 |
| **战斗记录** | 本人参战、看到明确伤害或击杀 | 已见战术结果、遇险代价、已见掉落物（若真实取得） | 自动揭露致命弱点、保证掉晶或保底素材 |

- 图鉴是**个人见闻档案**，不是开局赠送的世界百科或绝对真理。玩家可以通过口述、普通地图和现场记录相互分享，但**一人的见闻不会自动同步到全体参与者**。系统短标签里的名阶是系统判定，人物自行添加的习性笔记可能不完整或误判，须标为观察而非系统认证。
- 图鉴不会记录尚未真正看见的「鱼人」等后续物种等级；不自动列全套未知物种、隐藏关卡、剧情真相、净化规则或医院收治机制。**病人永久登记、院长出场阈值和医护越界原因**不能从图鉴直接解答。
- **S「定罪」仍是阿禾专属主动能力**：发现某个具体怪物的**致命软处**，但知道弱点也未必能穿甲或命中。普通系统识别和图鉴**永远不自动展示这一级信息**，其他人只有听阿禾实际说出或亲见攻击结果才可能了解。
- **晶体与材料只能按事实取得。** 图鉴可以记下亲眼看见和实收的战利品，却不承诺怪物必掉晶体或特定等级必掉某物。系统短标签不附血条、精确战力值、伤害预测、地图标点或「可击杀」按钮。

## 四、第一季已写76集的补写适用边界

- **EP002—003** 游轮公示的是参与者天赋评级和共同任务；**尚未遇见实体怪物，不会凭空开放一整本图鉴**。EP005第一次看到骨犬本体时，系统即显示其名称与阶位。
- **EP006** 废镇大量巨鳄：任何进入参与者视线的个体都有名阶浮字，**群体数量仍靠人亲眼点数**；完全藏在墙后或其他遮挡物后的个体不触发，系统不会直接扫描二十只怪的位置。
- **EP008** 夜里只要缝声人本体进入参与者视线，即显示**【缝声人·I阶】**，不要求靠近或看清全身；先前只听见熟人求救声不能提示它的真实身份，何雨误判和死亡因果保留。
- **EP013—018** 初见铁颚时，只要看到巨鳄本体任一部分便会显示**【巨鳄·III阶】**；任务身份**「铁颚」**仍需经真实证据与任务模块确认。唐梨发现软甲位置依靠真实侧视和既有能力，不因看见浮字自动掌握。
- **Day5起疗养院**：参与者直接看见鬼护士／鬼医生本体时即能短显名阶，**不泄露医护职能、永久登记规则或院长凝形条件**。
- **EP053—059** 南林熊群：能目视的个体分别有**【魔熊·II／III／IV阶】**；十六只需团队逐只目测计数，藏在柴堆与渠下的个体不提前扫描；IV暂困与左眼角擦痕仍由现实战斗造成。
- **EP063、EP074** 夜巡者、缝声人：本人直接看见怪物本体时即显示名阶；只听到刃臂声或假语声不能提前触发。
- **EP068—070** 四阶鬼院长：四人视线首次落到鬼院长本体时即得**【鬼院长·IV阶】**，无须靠近或看清全身；此前三楼空椅上的黑雾只是观众客观镜头，不为角色提前解锁。
- **EP075—076** Day14完全永夜：坑底爪痕、吼声或完全遮挡下的动静不能触发名阶提示；周启透过木隙直接看见魔熊、鬼院长本体的可见部分后，分别更新为**【魔熊·V阶】**和**【鬼院长·V阶】**，直接看见两名鬼医生本体后也识别其升为IV。**升阶是世界真实事件，浮字只在角色重新看见对应怪物后更新**，不能倒置因果。

## 五、使用优先级

1. 以本文件确定**识别触发、图鉴权限、任务专名例外与UI展示**。
2. 以[08｜正式命名](08_怪物区域_正式名称与正史优先规则_v1.0.md)确定物种名称、已锁出没区域及世界事件；[03｜医院机制](03_怪物与疗养院机制_现行规则.md)确定抓捕、诊疗、永久登记和鬼院长介入；[05｜天赋](05_天赋技能_战力成长_团队战术.md)确定「定罪」与力量代价。
3. 第一季原五阶段文件保留角色动作、真实遭遇、战斗后果；新增提示**不重写战术本质**，冲突处要具体修正文案与知情边界。旧历史草案中的泛化自动扫描、开放全图百科、必掉晶体等写法一律不追认为正史。
