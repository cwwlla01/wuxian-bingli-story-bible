# 04｜人物、三人格与首批十五人

> 第一季人物入口。**【确认】**标识已有作者明确的身份、人数及能力规则；具体心理戏与对话仍以[五阶段现行大纲](../大纲/README.md)为准。本季当前设定不包含“忏悔”技能或第二岛人格书信情节。

## 林渊、阿禾、阿月：同体但不同主观

- **林渊**：男性心理医生，主天赋C「共情」，只能感受附近生命的情绪强度和倾向，不能读心、读取怪物规则或自动识别要害。曾在现实医院照护阿禾，但他对她过往客观知悉的范围有限。
- **阿禾**：与林渊共享**一具男性肉身、一个挑战者名额**的独立女性人格，承载S「处刑者」。有自己的主观记忆、疼痛与情感，不是“战斗皮肤”。阿禾的人格记忆自幼在福利院长大，习惯靠自己、不轻易信任他人，对陌生人保持清晰边界；她话少、外冷、带攻击性，心软时通常用挡在前面或把事情做完来表达，不会忽然变成热情照料者。阿禾与现实阿月曾相爱，因歧视与家人逼婚而分离；现实阿月死于**自杀**，阿禾长期自责。她的主观成长记忆不能直接写成林渊这个男性在现实中亲历了同一段女性人生；共身的终极成因留待后续。
- **阿月（岛上人格）**：来自阿禾对现实逝去恋人的哀思与仪式，有独立主观感受，**不是现实逝者魂灵复活**。她不能主动发动S技能；他人亦不能要求她代表现实亡者“必须原谅”。
- **共身规则**：肉体伤害、疲劳、刑纹在人格间持续存在；**早期记忆、战斗经验不自动共享**。极端危机可能触发阿禾接管，但叫名字不是可靠开关；阿禾在**真实夜晚完成假发＋镜子＋化妆**后，阿月才可能接管；次日**真正日出**回切阿禾。Day13最后一次日光后，因可能无法回切而放弃第四次。
- **季终**：Day15阿禾「处刑」严重反噬后，**同一男性肉身一直昏迷，林渊没有趁机自动接管**；周启在B1冒医护巡查风险照护，陈七与小满因永久登记在院墙外接应。Day18林渊醒后**只能从自身旧医院经历与阿禾曾告诉他的事出发**，并听队友讲Day15战斗，**看不到阿禾三天的梦**。他在出院墙后**征询阿禾是否愿意出来**，不是掌握自由开关；阿禾同意，Day12岛上阿月人格托小满的“我从来没怪过她，能认识她我很开心”才由小满在海边亲口交给阿禾。现实新船靠岸后转入意识世界，阿禾说“林医生，谢谢你”，林渊沉默微笑，焦树新芽定格。

## 人物经历、天赋与精神源头

> 人物职业、心理来源与造型按本节设定执行。苏小满、陈七、周启的核心经历沿用作者明确设定；其余人物按人物性格、剧情作用与天赋意象统一落实。各项能力的心源因果遵循[天赋心源规则](05_天赋技能_战力成长_团队战术.md#天赋的心源映射)；人物不因此获得超出技能边界的能力。

| 人物与天赋 | 现实身份与精神关系 |
| --- | --- |
| **何雨｜B·息隐** | 社区服务窗口的活动协助人员。她从小在家人争吵时习惯缩小自己的存在感，觉得“不被看见就不会再添一把火”，这种自我隐去的愿望长成「息隐」。但她并非冷漠：听见熟悉的求助声仍会走出去确认，能力与善意之间的矛盾保留了她首夜遇险的因果。 |
| **赵骁｜A·狼型兽化** | 小城社会青年，长期混迹本地圈子，靠讲义气、替人出头和争取位置建立自己的小团体。狼型力量映出他对“兄弟”和群体认同的执念，也映出他想成为能决定方向的强者。危机压顶时，他把“保住群体”逐渐缩窄为“先保住自己认可的核心、尤其是自己”，背叛来自一步步自我辩护，而非天赋把他变成恶人。 |
| **韩震｜A·铁骨** | 仓储物流班组工。家里和工作上都常被当作最能扛的人，久而久之不习惯求助；「铁骨」源于“只要我不倒，后面的人就还有时间”的信念。人物弧光落在坚韧不等于没有极限，而不是单纯硬汉。 |
| **罗峰｜A·影跃** | 大家族出身的青年，家教、资源和人脉都不缺，却长期被家族规划牵引，渴望走出别人替他安排的路线。「影跃」对应他挣脱掌控、按自己意志抵达另一处的愿望；他行动敏捷也可能是在逃避停下来面对家族与自身的冲突，保留冒进后的恐惧和后悔。 |
| **唐梨｜B·声呐回声** | 小型演出场地的现场音频助理。她熟悉噪声，却有过“说了很多、彼此仍听不见”的关系经验；能力映出她想在混乱中确认回声、知道远处是否有人回应。它只给她有限的听觉线索，不是预言或全图定位。 |
| **吴大勇｜B·狂力** | 建材搬运/施工后勤人员。过去曾有一次想把人拉出险境却觉得自己力气不够的经历；「狂力」从“这次我得有力气把人拉回来”的执念生长出来。铁颚战的牺牲兑现保护选择，但不把死亡包装成他终于证明价值。 |
| **孙浩｜B·火种** | 餐饮后厨帮工。对他而言，火先是有人等他回去吃饭的灯与热食；生活长期缺少稳定感后，他格外想留住一小团能照亮、取暖的东西。「火种」因此连着家的温度和“我也能给别人一点光”，而不是因为做饭才获得火能力。 |
| **许知意｜B·凝血** | 普通行政人员，参加过基础急救培训。曾遇到在意的人受伤流血、自己只能压住伤口等待救援；她想要的不是万能治愈，而是先让流失停下来、替人多争取一点时间。能力仍只负责止血，不替代治疗。 |
| **马青青｜B·危兆预感** | 会务/活动执行助理。她习惯提前检查出口、天气和人流，也曾因提醒被说“想太多”；能力源于她想在坏事发生前先得到一点征兆。表现是模糊的不安或风险感，不能让她知道未来细节。 |
| **苏小满｜B·灵丝** | 大学生。父母感情破裂，她长期盼着把两人重新连接起来；「灵丝」从“我能不能把这个家牵在一起”的愿望衍生。专业不作为能力来源；人物成长是明白父母关系不是她一个人的责任。 |
| **林渊｜C·共情** | 男性心理医生。工作中常听见别人说不出口的痛，他盼望在对方开口前先察觉“此刻有多难受”，因此得到的是情绪强度与倾向，而不是答案、记忆或读心术。心理专业让他愿意倾听，却不能让他救下所有人。 |
| **陈七｜C·定点投送** | 高二学生，出生在农村，一直想离开村子；「定点投送」从想去远方、挣脱熟悉环境的愿望衍生。关键反差是他很想离开，能力却只能投送本人拿着的非活物，不能把自己传走；他仍须亲自走过路线、设置标记并承担代价。 |
| **魏叔｜C·固障** | 小区物业设备维修员。“家里很多东西坏了都等他修，但关系和人心不是扳手能修好”；他渴望至少有一道真正可靠、能替别人挡住危险的边界，「固障」由此成形。维修经验让他熟悉门闸等实物，但不能让他破解所有机关。 |
| **刘斌｜C·引惑** | 社区便利店夜班店员。日常常被顾客和熟人忽略，心底很想有人停下来听他说完、在他招呼时回头；「引惑」映出这种渴望被注意和回应的需求。它不等于操纵思想，也不把他写成天生会操控人的反派。 |
| **蒋文｜C·异鉴** | 工厂来料质检员。工作与生活里都怕自己把异常看漏、让错误混过去；「异鉴」像是“让我看出哪里不对”的愿望。它只能辨认设定允许的差异，不自动给出真相、用途、弱点或完整答案。 |
| **周启｜A·不死战躯** | 上上批挑战者、退役特种兵教官，经历过许多任务；长期被要求带人进险境、再把队伍带回来，「不死战躯」从“我不能倒在任务中”的生存意志衍生。它不等于真正不死：死眠时无法自卫，仍需活人触肤唤醒，伤势与长期代价继续存在。 |

**共身人格的补充：** 阿禾是林渊同一男性肉身里的独立人格，现实职业不另造；她的人格记忆里有福利院成长经历，形成“不求人、先守边界”的孤狼策略。她的S「处刑者」源自现实阿月死后长期自责、习惯先惩罚自己的心理；福利院经历解释她如何把脆弱藏起来，不替代阿月之死造成的自责根源。阿禾的自责不是事实上的罪责，也不改写阿月之死。岛上阿月没有主动技能，是阿禾哀思与仪式中形成的人格，不是现实亡者魂灵。现实阿月生前是社区书店店员，不承担“治愈阿禾”的功能。

### 写每一句对白之前，核对四件事

1. **这句话是要做什么？** 求助、拒绝、试探、掩饰、劝阻、争取时间、安慰或命令；不能所有人都替编剧解释机制。
2. **谁实际知道？** 林渊不能读阿禾战斗记忆；小满能证实赵骁拉闸，其他人需听她讲；周启不预知现行院规；阿禾不知道Day12阿月托话。
3. **压力下会变成怎样？** 林渊越无力越克制，直到熟人连死才崩溃；小满越害怕越需选择是否挺身而出；赵骁先试图带队，后来有意识地牺牲别人；周启命令简短，但会因旧伤和守夜疲惫失误。
4. **删掉角色名还能分辨吗？** 若林渊、周启、阿禾都在说“大家冷静，按计划行动”，就重写。优先改**词汇、句长、关注点、行动与停顿**，不机械给每人固定口头禅。

**特别禁忌：** 小满不是现实阿月替身；阿禾和阿月性格、说话方式及主控记忆不同；林渊的治疗职业不让他精准治愈每个人；赵骁的背叛必须先有前期真实贡献；有温柔也可反驳，有胆怯也能救人。**Day18小满的完整托话只能在海边由她亲口交给清醒且自愿出来的阿禾**，阿禾最后只说已锁定的“林医生，谢谢你”，不让所有角色轮流讲主题总结。
