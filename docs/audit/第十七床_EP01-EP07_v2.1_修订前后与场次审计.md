## C. 必须严格遵守的院内机制

1. **值班者抓人、押送、正式登记**；执刀医师仅接收已送达的患者和**对应病床的旧病历**近身矫正，绝不跑到走廊代劳抓人。旧病历是**跟3F017床**的，不是陈七疾病史；具体诊断还没被作者锁定。
2. **陈七登记不可逆**。EP02前即使身在院墙内，尚无“已登患者全院精准定位”；EP02最后一笔落下后，所有医护包括留在治疗区的医生都能精准感应；EP05越墙瞬间丢失登记定位，腕带扯掉不注销。未来重入院墙**立即重启**，不能侥幸换空床消除。
3. **精准感应不是追捕瞬移，更不是全员改本职**。值班者必须沿楼梯/门廊到场。房门、工具箱、锈销只给短暂时间差；医生即使知道位置也不放弃病历治疗职能。
4. **院长两个独立出场原因**：持续严重的收治流程受阻，**或**值班者/医师死亡过多。本篇只表现一次登记后紧接着的短时逃逸，周启不杀医护；不构成作者已定的院长必出现条件。原v0.8尾声候选R-01/双红叙事不在新EP05承担当晚触发。
5. **院墙外并非外怪不能进也非绝对安全**。从墙外被看见仍可能有普通视觉跟踪；新版EP05安排墙外实体转角，才阻断普通视线，绝不让整院怪物因失感应瞬间静止。上一晚普通骨甲猎犬止步原因仍是独立悬念。

- 【候选场景】3F A门从走廊向楼梯打开；门扇实际扫过的石面能由EP01陈七亲手触标；约3m楼高+楼梯折角仍在陈七**实际短距能力上限**；轻空铁盒体积/门扫弧能阻一次但不完全堵死，须有正式平面与动作物理复核。
