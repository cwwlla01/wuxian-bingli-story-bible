# 待完善问题｜2026-11-03 新增苏小满与疗养院线

> 最新作者明确确认的高中生前史、救生圈沉底、黄毛队杂役、三人返仓熬夜、疗养院外怪物止步、陈七首次唤醒周启、第三夜机制怪，已经收录于 STATUS 和新人物档案。下列内容依然【待定】。

## 第一优先｜准备写分集前处理

1. **仓库死亡视觉**：魏叔、刘斌、蒋文都死；小满目睹哪一位被吞食？三人死亡先后如何体现，既定人数不可改变。
2. **初期时钟**：首船离港后22小时黑夜、2小时光亮。仓库第一长夜、物资搜索、院墙第一夜、三楼发现周启、疗养院第三夜，先按“到达院墙为第一夜”排表，起算方式待最终确认。
3. **前往疗养院**：镇子被搜光，三人为何来不及折回？道路、坡度、追兵种类与距离都要有具体行动支撑。
4. **外部怪物为何止步**：只确认当次追兵停住；不能将所有种类怪物一律设为永远不能进入疗养院。是否与院长/值班者机制有关尚未确定。
5. **周启为何从地下室到三楼**：谁或什么可能移动了他、何时发生、周启自己知道多少？先留谜团，不擅自认定是整岛重置。
6. **第一次唤醒周启**：已改成陈七检查身份时直接接触；动作需体现活人直接触碰与反手抓住，不写成睡梦中自主苏醒。
7. **小满被怪物拖走**：怪物属于哪一类、去向与救援空间、她如何喊出“小禾救我”、林渊如何被惊恐与保护冲动刺激、阿禾何时重新退场。
8. **镜子与假发**：阿禾为何收走，实物从哪儿来、谁保管、何时自愿完成真实化妆；阿月不能只是看到假发便即时出现。
9. **疗养院第三夜机制怪**：身份、触发条件、进攻路线、失败代价和可观察的反制窗口。不可临时发明全岛独有第八物种或“院长立刻掌控全楼”。

## 第二优先｜角色与战术

10. 苏小满的具体年龄与年级、父母争吵的两三件代表小事；不能给家庭额外加虐待、酗酒等未确定因素。
11. 黄毛队具体让小满做什么杂活、她明明B级却如何被低估；至少有一件可演的微小尝试和失败。
12. 小满与阿月“有点像”的具体容貌点，以及她崇拜阿禾后如何发展独立人格，不把小满当阿月替身。
13. 三人单挑只勉强持平I阶，周启训练必须分阶段有实际收益、又不凭空变得可单挑高阶。
14. 周启未来第二次死眠仍由陈七主动直接触碰唤醒，要与三楼第一次好奇触碰区别开。
15. 疗养院1—3楼找到的“水”是否安全可饮；物资数量、携带、库存与搜查时间。
16. 高僧寺庙句已定“念头起时，你看见它；念头落时，你不必追它。”；仓库另一句关键点拨仍待选择。
17. 横屏16:9是方向；单集60—90秒和总量100—120集仍未最终锁定。
