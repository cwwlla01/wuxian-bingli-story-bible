# 待完善问题｜按因果重要性排序
## 优先级高
- 小满险坠海但获救，如何让众人具体看见“海无浮力”？落海物件、漂浮失败或其他可演出的证据尚未锁定。
- 小满与阿月相似的部位、她胆小的前史、灵丝成长及独立的关键选择。
- 仓库内小满在何位置、她的相貌怎样与林渊/阿禾潜意识衔接；避免信息向观众过早泄露。
- 高僧已确定原话“念头起时，你看见它；念头落时，你不必追它。” 仓库里的另一句关键台词仍待确认。
- 林渊为何从小人格分化、现实小禾与同体阿禾关系为何，不能擅自定成附身或真实阿月归来。
## 优先级中
- 周启训练三人的分阶段技能与团队救援回报。
- 东部泵站为何非去不可，疗养院为何无法防守，裂谷获取洁净水的因果。
- 服装、假发、化妆品、留言、钥匙与定点投送标记在岛重置后的状态。
- 游轮72小时任务与15天航次、新人登岛、怪物48小时替代个体重生的时间账。
## 长线留白
- 系统起源与真正任务、现实中挑战者已经死亡之谜、七彩光柱本质、林渊临终记忆。
