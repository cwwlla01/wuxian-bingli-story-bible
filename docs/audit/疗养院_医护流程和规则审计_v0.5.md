# 疗养院三职能体系 v0.5｜规则状态机与漏洞审计（工作提案）

> 基础来源：创作者关于「值班者／执刀医师／院长」三层职能的最新提议，旧《七类怪物》分册及疗养院推理主线。**新职能与技能仍为【工作提案】**，并未写入正式正史。

## 1. 医患身份的可见状态链

| 状态 | 事件 | 谁能推动 | 剧情后果 |
|---|---|---|---|
| S0 无登记 | 未登记者藏于**无病历空床** | 主角主动寻找、进入；仍可被实体目击 | 按作者本轮要求，通常能躲开**正常收治**，不是全时免疫或正式出院 |
| S1 被捕与候分配 | 值班者发现/抓到人，实际控制并移往登记点 | 值班者 I–II | 仍可挣扎或被同伴阻断，不能隔空成为“患者” |
| S2 已登记床位 | 有床号、患者记录，或被错误绑定旧病历 | 值班者，需可见文书/腕带/床号信息 | 真正进入医生能识别的对象范围 |
| S3 病历复核 | 医师近身核对病历与身体 | 执刀医师 II | 发现实际差异；**其本人也可能跳过必须的身份核验步骤而违规** |
| S4 病理矫正 | 医师通过真实近身操作尝试匹配病历 | 执刀医师 II | 可被及时中断，危及身体，不能凭空远距变形 |
| S5 追加诊断 | 真实治疗产生的伤势被列为待办 | 医师持病历登记 | 治疗越多，待处理越多；不能凭空登记不存在的伤 |
| S6 可申请正式出院 | 全部诊疗完成、无待处理异常 | 病床/病历状态需核验 | 仅达到申请条件，**尚未取得院长审批** |
| S7 正式出院 | 院长最终签字 | 院长 III 特殊个体 | 作者明确要求的**唯一**正式出院路径 |

**S2→S3错误分配**是《医生也会被收治》的核心漏洞：值班者误分配床位后，医师也未核验患者身份便继续诊疗，两者违规可分别被核查。院长查到**具体谁犯了什么错误**才能决定问责。

**临时物理逃离**：从S2–S5挣脱并逃出治疗区，只是“逃脱追击”，不自动跃迁至S7，病历/患者状态也不自动清零。除正式出院仍无特殊豁免。

## 2. 总查房的公平性检查

- **启动**：须有较严重、可观察并能被下级报告的秩序冲突，例如多处床位登记失配、非正常转运/中断治疗等。具体数量阈值尚待作者决定。
- **预警**：先由值班者报告/通路异常，院长胸腔共鸣；随后医护暂停平时路线上各自的事务、编队到指定病区。
- **覆盖**：信号有局部传达/回报能力，但值班者必须真实行走、搜门、核床、取病历；无建筑级透视、无随叫随到的跨层瞬移。
- **空床**：无病历空床可在常规查房中不进入登记流程；**总查房**中如果医护真实检查空床并亲眼看到人，仍然有危险；不等于作者已允许对未登记者自动扫描。
- **中断**：破坏一条回传或共鸣器官可能削弱局部协调，**不会使所有医护停机**；未必立刻解除已经形成的搜索路线。
- **时长**：行动需真实耗时，信号前兆给主角有限行动窗口，并非持续固定小时数的魔法。

## 3. 医疗问责的真实性检查

- 院长不能从主角一句控诉中自动读取真相；要**亲自或通过具备实体信号的近处医护核实**床号、病历、病人、术前身份核对等。
- 如果核查出医生流程错位，院长可以真实抓捕、约束并收治医生；**值班者若也违反登记程序，同样可能成为问责对象**。制度对医护和人类都一致，但具体处分内容是其病态行为，不等于现实医疗流程。
- 有序执行的医师并非只要小满出示一张纸就会被抓；每次都要出现新的实质错误，且有证据让院长看见。48小时同族同阶补充的新个体不会继承先前医师的记忆。
- 院长问责时应腾出真实注意力/人员，才能让陈七的队友抓到短暂逃生窗口；不能“院长判错→全院冻结→主人公自动出院”。
- 医疗问责不取消原有登记记录，正式出院只走唯一审批线。

## 4. 医生能力与院长能力的彻底切割

| 能力/权限 | 值班者 | 执刀医师 | 院长 |
|---|---|---|---|
| 日常查房与床位分配 | **负责** | 不负责主要登记 | 监督、可复核 |
| 病历对照 | 只核床位/是否有文书 | **负责近身全面对照** | 只审流程，不执行临床“矫正” |
| 病理矫正、无菌切割、追加诊断 | 无 | **专属** | **无** |
| 总查房组织 | 接令参与 | 依令保留/暂停治疗 | **发起与调度** |
| 对违规医护实施收治 | 受命执行 | 可能成为对象 | **审批/亲自执行** |
| 强制清场III级体格压制 | 无专属III | II级近身格斗 | **专属骨质前肢/夹钳** |
| 最终出院审批 | 无 | 无 | **唯一签署者** |

## 5. 与既有已写剧情的冲突消解

1. 旧《七类怪物》里院长“矫正、病态治疗”的表述属于被**新工作提案拟替换**的旧方案，原始文档保留作历史，不把差异直接标注为创作者已定正史。
2. 第三夜推床抓清醒陈七的**候选**场面，应先归类为**值班者执行抓捕/分床**。若没有记录核验和独立医师出场，不能算实际病理矫正；III院长不要直接以普通医师身份出现。
3. 三人从周启B1→3F推测机制依然成立，**不能据此断定执行者是哪一种职能**。他们最初只知道有人/某物移过周启；看到值班者、执刀医师也不能立即知道谁完成了旧事。
4. 小满第二次遇险喊小禾后阿禾救援、收镜子假发等事件不受新怪物设计影响；不能因为医生能力更危险就让人格变成战斗快捷键。
5. 院长既掌握更强组织能力也具III级实体战力，但不能让其“听见全院心跳”或以手术能力无条件干掉周启。

## 6. 最值得作者补定的5个条款

1. 病历来自谁、保留多久；新来的挑战者如何被正式登记为旧床位“患者”？
2. 无病历空床在正常查房中为何不被注意；进入总查房后哪些实际物证会使躲藏失效？
3. 什么算“严重诊疗秩序混乱”？给一条可以提前看见的启动条件。
4. 规范墙牌和床号登记如何能被主角接触，院长为何可能碰巧在纠纷发生时经过；别让智斗依靠超自然运气。
5. 医护错误会让院长优先问责到何种程度？医生被收治后陈七仍处什么登记状态、院长是否立刻恢复对他的审查？

> 核心方向：**怕被抓 → 怕被“治” → 怕整栋院区被组织起来**。这不是三位怪物依阶位单纯增伤的升级。
