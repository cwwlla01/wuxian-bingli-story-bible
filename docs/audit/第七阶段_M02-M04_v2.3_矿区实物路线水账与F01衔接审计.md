## 三、空间地图和V的接地感知只由物证推断

```text
南林站（留2×1L未开水）
   └──旧施工路数小时→矿区外缘旧轨道〔旧矿车靠裂木挡块固定〕
                         │ 一次落石撞车，巨兽几息后实际转向
                  挡土墙背面──外棚侧门──旧应急水柜（后4瓶被重架压住）
                         │             │
                  陈七实摸空基石←陈七从手里投4瓶袋到基石
                         │
                  小满M02记下的外侧排水石坎──轻铁网实开
                         │
                  旧断丝钩破布袋→1瓶滚矿坡（真实舍弃）
                         │
                  绕旧矿车围栏的外缘林坡（陈七携3×500mL）
                         └──F01真实II拾声者突袭（本次未提前发生）
```

M02 SC02见矿车仅**滑动小段**、旧挡块已有裂缝；M03 SC02见**同一挡块终断、矿车再次真正顺坡下滑**，实物撞击和巨兽转向共同产生采石坡落石。人物仅知道**“撞轨后它转向”**，不等于掌握“它只会感知震动/对话无效/绝对无法进林区”的通用规则。巨兽体量大、转身占空间，有实际响应过程；并未瞬移到仓棚入口，也未被四人“远程控制”。

M02 SC03陈七先走到基石**亲手设置空点**，M03 SC02从自己手里把真实袋送去基石，再**经真实侧门/挡土墙实路走到外石拾回**。M04从早先观察到的排水石坎实际清除轻搭钩、逐人走过，林坡仍可能有新怪；从矿区外缘撤出不代表已走到林业站或港口，也不意味着V阶必然不能追出域。

## 四、人物弧线付回报与余留

- **林渊**：M02坚持外缘勘查而非闯深裂谷，M03在陈七想取更多瓶时用实际重架风险叫停，未靠C「共情」阅读巨兽想法。他可以信任队友所见事实，不必每句都问周启。
- **陈七**：M02标真落点、M03合法短投2kg左右物品；M04正因失去一瓶完整500mL旧水而想冲下坡，最后被小满以真掉石证据劝住，**保住人与剩三瓶**，不是自称学会了不怕失去。
- **苏小满**：M02发现矿车和巨兽之间的时间关系**但不臆断全能力**，发现外侧排水石坎候选回路；M03正确指出重架受力不稳；M04她用短灵丝只牵**轻搭钩**、实际手扶开网，再基于真实松坡落石主动喊停陈七。她有与A05被阿禾救、R03救导师不同的**主体判断**，不是靠新增B级战力获得优越感。
- **周启**：R03被迫提前醒而肋伤未愈，M02走数小时须多次休息；M03只挡很轻一片木板且继续痛，M04要林渊扶着走狭石坎。**不再新增第三次死眠**，更没有满血正面打V。
- **阿禾/阿月**：本M02—M04没有新的主控切换；F01的保护危机仍会触发阿禾，F02夜间化妆才可由阿禾主动制造阿月现身条件，阿月不是新独立肉身，也不是矿区自动出现的幻影。F01原稿“未沿真实山道归巢的II拾声者”属于v1.4的后续候选，与本段“外缘看见坏围栏却没辨怪”不冲突。
